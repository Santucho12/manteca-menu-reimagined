# Menú digital: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Catálogo mínimo de productos, administración del menú en `/admin/menu` y la página pública en `/` leyendo de la base.

**Architecture:** Cinco tablas con RLS de solo lectura para el admin; toda escritura por funciones `security definer` de la base, una por acción. El público lee la vista `menu_publico`. Servicios en `src/lib/menu/` (lógica pura aparte, probada sola), acciones de servidor por pantalla, componentes sin lógica.

**Tech Stack:** Next.js 16 (App Router), React 19, Supabase (Postgres, RLS, Storage), Zod 4, React Hook Form, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-08-menu-design.md` (y `docs/modulos/02-menu.md`).

## Global Constraints

- Quién decide: solo Santiago autoriza aplicar una migración a la base real, publicar, mergear a `main` y cualquier excepción.
- TDD: primero el test, verlo fallar y commitearlo; después el código, en otro commit. Código escrito antes que su test se borra y se rehace.
- Tests sin mocks: nada de `vi.mock`, `vi.fn` como reemplazo, `page.route` ni clientes falsos. `*.base.test.ts` usa la base de pruebas; cualquier otro `*.test.ts` es puro.
- Mientras se construye: cada tarea corre sus tests nuevos (pantallas: su archivo de Playwright solo en `--project=computadora`) y `npm run tipos`. Al cerrar: `npm run verificar` y `npm run e2e` completos.
- Largo: 20 líneas por función en `.ts`, 80 por componente en `.tsx`, 300 por archivo, sin contar blancos ni comentarios. La lógica no vive en los `.tsx`.
- Idioma: nombres, comentarios, base y mensajes en español; pantallas en rioplatense con voseo. Comentarios del porqué, no del qué.
- Datos: sesión del usuario y RLS; el local sale de la sesión; los precios, de la base o del cálculo en el servidor; nada se borra; toda escritura deja auditoría; la clave secreta solo en tests (`clienteSecretoDePruebas()`).
- Plata: `bigint` en la base, `number` entero en TS, nombres con `_centavos` o `Centavos`. El público ve pesos enteros (`$4.000`).
- Estilos: colores y tipografías de `src/app/globals.css`; componentes de `src/components/ui/` y `src/components/formularios/`.
- Bases: migraciones con el MCP `supabase-pruebas` (`apply_migration`); nunca el MCP `supabase` general; la real no se toca en este pedido.
- Git: rama `feat/menu`, commits chicos en español con conventional commits, `git add` archivo por archivo, nunca `-A`.
- Bash en esta máquina: los comandos largos fallan y los heredocs pierden `\\`. El código se escribe con Write/Edit.

## Review Focus

1. Un producto en una categoría con precio compartido que tiene precio propio en una sola presentación: el público ve el compartido en el subtítulo y el propio con su etiqueta (Task 9).
2. Un aumento negativo fuerte con redondeo grande sobre un precio chico: nunca baja de un paso, nunca llega a cero (Task 8).
3. Un nombre con comillas, `%`, emojis o 100 caracteres en categoría y producto: se guarda y se muestra tal cual (Task 4).
4. Dos admins: uno mira la vista previa del aumento y el otro cambia un precio antes de aplicar: se rechaza todo (Task 6).
5. Un producto reactivado cuya categoría sigue desactivada: no se reactiva y el mensaje dice qué hacer (Task 5).

`tests/menu-de-prueba.ts`:

```ts
import { randomUUID } from 'node:crypto';
import type { Cliente } from '../src/lib/supabase/cliente';
import { clienteSecretoDePruebas } from './clientes';
import { asegurarLocalB, idDelLocalPrincipal } from './locales';

export type SemillaDeCategoria = {
  otroLocal?: boolean;
  visible?: boolean;
  activo?: boolean;
  presentaciones?: string[];
  // Un monto por presentacion, en centavos; null es sin precio compartido.
  compartidos?: (number | null)[];
};
export type SemillaDeProducto = {
  visible?: boolean;
  activo?: boolean;
  // Un monto propio por presentacion, en centavos; null es heredar.
  precios?: (number | null)[];
  etiqueta?: 'mas_vendido' | 'artesanal' | 'nuevo' | null;
};
export type CategoriaSembrada = {
  id: string;
  nombre: string;
  localId: string;
  presentaciones: { id: string; nombre: string }[];
};
export type ProductoSembrado = { id: string; nombre: string };
type TablaDelMenu = 'categorias' | 'presentaciones' | 'productos' | 'precios' | 'aumentos';

export function nombreDePrueba(prefijo: string): string {
  return `${prefijo} ${randomUUID().slice(0, 8)}`;
}

function comprobar(error: { message: string } | null, que: string): void {
  if (error) throw new Error(`No pude ${que}: ${error.message}`);
}

async function siguienteOrden(secreto: Cliente, tabla: 'categorias' | 'productos', filtro: Record<string, string>) {
  const { data, error } = await secreto
    .from(tabla)
    .select('orden')
    .match(filtro)
    .order('orden', { ascending: false })
    .limit(1);
  comprobar(error, `leer el orden de ${tabla}`);
  return (data?.[0]?.orden ?? -1) + 1;
}

async function insertarCategoria(secreto: Cliente, localId: string, semilla: SemillaDeCategoria) {
  const fila = {
    local_id: localId,
    nombre: nombreDePrueba('Categoria'),
    icono: '🥐',
    orden: await siguienteOrden(secreto, 'categorias', { local_id: localId }),
    visible: semilla.visible ?? true,
    activo: semilla.activo ?? true,
  };
  const { data, error } = await secreto.from('categorias').insert(fila).select('id, nombre').single();
  comprobar(error, 'sembrar la categoria');
  return data!;
}

async function insertarPresentaciones(secreto: Cliente, categoria: string, localId: string, nombres: string[]) {
  const filas = nombres.map((nombre, orden) => ({ local_id: localId, categoria_id: categoria, nombre, orden }));
  const { data, error } = await secreto.from('presentaciones').insert(filas).select('id, nombre, orden');
  comprobar(error, 'sembrar las presentaciones');
  return data!.sort((a, b) => a.orden - b.orden).map(({ id, nombre }) => ({ id, nombre }));
}

async function insertarPrecios(
  secreto: Cliente,
  categoria: CategoriaSembrada,
  productoId: string | null,
  montos: (number | null)[],
) {
  const filas = categoria.presentaciones
    .map((presentacion, i) => ({ presentacion, monto: montos[i] ?? null }))
    .filter(({ monto }) => monto !== null)
    .map(({ presentacion, monto }) => ({
      local_id: categoria.localId,
      presentacion_id: presentacion.id,
      producto_id: productoId,
      monto_centavos: monto!,
    }));
  if (filas.length === 0) return;
  const { error } = await secreto.from('precios').insert(filas);
  comprobar(error, 'sembrar los precios');
}

/** Una categoria de prueba con nombre unico, visible y activa salvo que se pida otra cosa. */
export async function sembrarCategoria(semilla: SemillaDeCategoria = {}): Promise<CategoriaSembrada> {
  const secreto = clienteSecretoDePruebas();
  const localId = semilla.otroLocal ? await asegurarLocalB(secreto) : await idDelLocalPrincipal(secreto);
  const { id, nombre } = await insertarCategoria(secreto, localId, semilla);
  const nombres = semilla.presentaciones ?? ['Unidad'];
  const presentaciones = await insertarPresentaciones(secreto, id, localId, nombres);
  const categoria = { id, nombre, localId, presentaciones };
  await insertarPrecios(secreto, categoria, null, semilla.compartidos ?? []);
  return categoria;
}

/** Un producto de prueba. Por defecto, visible y con $1.000 en la primera presentacion. */
export async function sembrarProducto(
  categoria: CategoriaSembrada,
  semilla: SemillaDeProducto = {},
): Promise<ProductoSembrado> {
  const secreto = clienteSecretoDePruebas();
  const fila = {
    local_id: categoria.localId,
    categoria_id: categoria.id,
    nombre: nombreDePrueba('Producto'),
    etiqueta: semilla.etiqueta ?? null,
    orden: await siguienteOrden(secreto, 'productos', { categoria_id: categoria.id }),
    visible: semilla.visible ?? true,
    activo: semilla.activo ?? true,
  };
  const { data, error } = await secreto.from('productos').insert(fila).select('id, nombre').single();
  comprobar(error, 'sembrar el producto');
  await insertarPrecios(secreto, categoria, data!.id, semilla.precios ?? [100000]);
  return data!;
}

/** Una fila de una tabla del menu, leida sin RLS. */
export async function filaDe(tabla: TablaDelMenu, id: string) {
  const { data, error } = await clienteSecretoDePruebas().from(tabla).select('*').eq('id', id).single();
  comprobar(error, `leer ${tabla} ${id}`);
  return data as Record<string, unknown>;
}

async function idsDe(secreto: Cliente, tabla: 'presentaciones' | 'productos', categorias: string[]) {
  const { data, error } = await secreto.from(tabla).select('id').in('categoria_id', categorias);
  comprobar(error, `leer ${tabla} para limpiar`);
  return (data ?? []).map((fila) => fila.id);
}

/** Borra lo que sembro un test, con su auditoria. En la aplicacion nada se borra. */
export async function borrarMenuDePrueba(categorias: string[]): Promise<void> {
  if (categorias.length === 0) return;
  const secreto = clienteSecretoDePruebas();
  const presentaciones = await idsDe(secreto, 'presentaciones', categorias);
  const productos = await idsDe(secreto, 'productos', categorias);
  const precios = await secreto.from('precios').select('id').in('presentacion_id', presentaciones);
  const aumentos = await secreto.from('aumentos').select('id').in('categoria_id', categorias);
  const todos = [...categorias, ...presentaciones, ...productos, ...(precios.data ?? []).map((p) => p.id)];
  await secreto.from('precios').delete().in('presentacion_id', presentaciones);
  await secreto.from('productos').delete().in('id', productos);
  await secreto.from('presentaciones').delete().in('id', presentaciones);
  await secreto.from('aumentos').delete().in('categoria_id', categorias);
  await secreto.from('categorias').delete().in('id', categorias);
  const ids = [...todos, ...(aumentos.data ?? []).map((a) => a.id)];
  const { error } = await secreto.from('auditoria').delete().in('registro_id', ids);
  comprobar(error, 'limpiar la auditoria del menu');
}
```

```sql
-- Menu (1 de 5): las tablas de categorias, presentaciones, productos, precios y aumentos.
-- El admin activo las lee en su local; nadie escribe directo: las funciones de la migracion
-- 3 hacen cada cambio entero o no lo hacen.

do $$
begin
  create type public.etiqueta_de_producto as enum ('mas_vendido', 'artesanal', 'nuevo');
exception
  when duplicate_object then null;
end
$$;

create table if not exists public.categorias (
  id uuid primary key default gen_random_uuid(),
  local_id uuid not null references public.locales (id),
  nombre text not null check (char_length(nombre) between 1 and 100),
  subtitulo text check (subtitulo is null or char_length(subtitulo) between 1 and 100),
  -- Una ruta de public/menu (carga inicial) o un objeto del bucket fotos-del-menu.
  foto text check (foto is null or char_length(foto) between 1 and 300),
  icono text not null check (icono in (
    '🥐', '🧈', '🍞', '🥨', '☕', '➕', '🥖', '🥯', '🍩', '🍪', '🧁', '🍰', '🥧', '🥪', '🍵', '🧃'
  )),
  orden integer not null,
  visible boolean not null default false,
  activo boolean not null default true,
  fecha_creacion timestamptz not null default now(),
  fecha_actualizacion timestamptz not null default now()
);

create index if not exists categorias_local_orden on public.categorias (local_id, orden);

-- Las formas en que se vende lo de una categoria. Sacar una es desactivarla: sus precios
-- quedan guardados y dejan de mostrarse.
create table if not exists public.presentaciones (
  id uuid primary key default gen_random_uuid(),
  local_id uuid not null references public.locales (id),
  categoria_id uuid not null references public.categorias (id),
  nombre text not null check (char_length(nombre) between 1 and 50),
  orden integer not null,
  activo boolean not null default true,
  fecha_creacion timestamptz not null default now(),
  fecha_actualizacion timestamptz not null default now()
);

create index if not exists presentaciones_categoria on public.presentaciones (categoria_id, orden);
create index if not exists presentaciones_local on public.presentaciones (local_id);

create table if not exists public.productos (
  id uuid primary key default gen_random_uuid(),
  local_id uuid not null references public.locales (id),
  categoria_id uuid not null references public.categorias (id),
  nombre text not null check (char_length(nombre) between 1 and 100),
  descripcion text check (descripcion is null or char_length(descripcion) between 1 and 300),
  etiqueta public.etiqueta_de_producto,
  orden integer not null,
  visible boolean not null default false,
  activo boolean not null default true,
  fecha_creacion timestamptz not null default now(),
  fecha_actualizacion timestamptz not null default now()
);

create index if not exists productos_categoria on public.productos (categoria_id, orden);
create index if not exists productos_local on public.productos (local_id);

-- Sin producto es el precio compartido de la categoria. Una sola fila por presentacion y
-- producto: quitar un precio lo desactiva y volver a cargarlo lo reactiva.
create table if not exists public.precios (
  id uuid primary key default gen_random_uuid(),
  local_id uuid not null references public.locales (id),
  presentacion_id uuid not null references public.presentaciones (id),
  producto_id uuid references public.productos (id),
  -- Pesos enteros para el publico, guardados en centavos.
  monto_centavos bigint not null check (monto_centavos > 0 and monto_centavos % 100 = 0),
  activo boolean not null default true,
  fecha_creacion timestamptz not null default now(),
  fecha_actualizacion timestamptz not null default now(),
  constraint precios_unicos unique nulls not distinct (presentacion_id, producto_id)
);

create index if not exists precios_producto on public.precios (producto_id);
create index if not exists precios_local on public.precios (local_id);

create table if not exists public.aumentos (
  id uuid primary key default gen_random_uuid(),
  local_id uuid not null references public.locales (id),
  porcentaje integer not null check (porcentaje between -50 and 200 and porcentaje <> 0),
  redondeo_centavos bigint not null check (redondeo_centavos in (1000, 5000, 10000, 50000)),
  -- Vacio: el aumento fue sobre todo el menu.
  categoria_id uuid references public.categorias (id),
  usuario_id uuid references public.perfiles (id) on delete set null,
  fecha_creacion timestamptz not null default now(),
  fecha_actualizacion timestamptz not null default now()
);

create index if not exists aumentos_local on public.aumentos (local_id, fecha_creacion desc);
create index if not exists aumentos_categoria on public.aumentos (categoria_id);
create index if not exists aumentos_usuario on public.aumentos (usuario_id);

-- Triggers

drop trigger if exists marcar_actualizacion on public.categorias;
create trigger marcar_actualizacion before update on public.categorias
  for each row execute function public.marcar_actualizacion();
drop trigger if exists marcar_actualizacion on public.presentaciones;
create trigger marcar_actualizacion before update on public.presentaciones
  for each row execute function public.marcar_actualizacion();
drop trigger if exists marcar_actualizacion on public.productos;
create trigger marcar_actualizacion before update on public.productos
  for each row execute function public.marcar_actualizacion();
drop trigger if exists marcar_actualizacion on public.precios;
create trigger marcar_actualizacion before update on public.precios
  for each row execute function public.marcar_actualizacion();
drop trigger if exists marcar_actualizacion on public.aumentos;
create trigger marcar_actualizacion before update on public.aumentos
  for each row execute function public.marcar_actualizacion();

drop trigger if exists auditar on public.categorias;
```

```sql
-- nunca queda sin precio: si el cambio lo deja asi, la funcion pide confirmar (PM101) y, con

create or replace function public.menu_exigir_admin()
returns uuid
language plpgsql
stable
security definer
set search_path = ''
as $$
begin
  if not public.es_admin_activo() then
    raise exception 'No tenes permiso para hacer esto' using errcode = 'PM100';
  end if;
  return public.local_del_usuario();
end
$$;

-- Tiene precio si alguna presentacion activa de su categoria tiene uno propio o el compartido.
create or replace function public.tiene_precio(el_producto uuid)
returns boolean
language sql
stable
security definer
set search_path = ''
as $$
  select exists (
    select 1
      from public.productos p
      join public.presentaciones pre on pre.categoria_id = p.categoria_id and pre.activo
      join public.precios pr on pr.presentacion_id = pre.id and pr.activo
       and (pr.producto_id = p.id or pr.producto_id is null)
     where p.id = el_producto
  )
$$;

create or replace function public.menu_validar_foto(la_foto text, el_local uuid)
returns text
language plpgsql
stable
security definer
set search_path = ''
as $$
begin
  if la_foto is null or la_foto = '' then
    return null;
  end if;
  if la_foto ~ '^/menu/[A-Za-z0-9._-]+$' then
    return la_foto;
  end if;
  if (storage.foldername(la_foto))[1] = el_local::text and exists (
    select 1 from storage.objects o where o.bucket_id = 'fotos-del-menu' and o.name = la_foto
  ) then
    return la_foto;
  end if;

end
$$;

-- Sin monto, el precio se desactiva y el producto vuelve a heredar el de la categoria.
create or replace function public.menu_poner_precio(
  el_local uuid, la_presentacion uuid, el_producto uuid, monto bigint
)
returns void
language plpgsql
security definer
set search_path = ''
as $$
begin
  if monto is null then
    update public.precios set activo = false
     where presentacion_id = la_presentacion and producto_id is not distinct from el_producto
       and activo;
    return;
  end if;
  insert into public.precios (local_id, presentacion_id, producto_id, monto_centavos)
```

```sql
-- Los hermanos de una categoria son las categorias activas del local; los de un producto, los
-- productos activos de su categoria.
create or replace function public.menu_vecino(el_tipo text, el_id uuid, direccion text)
returns uuid
language plpgsql
stable
security definer
set search_path = ''
as $$
declare
  el_vecino uuid;
begin
  if el_tipo = 'categoria' then
    select v.id into el_vecino from public.categorias c
      join public.categorias v on v.local_id = c.local_id and v.activo and v.id <> c.id
     where c.id = el_id
       and case when direccion = 'arriba' then v.orden < c.orden else v.orden > c.orden end
     order by case when direccion = 'arriba' then -v.orden else v.orden end
     limit 1;
  else
    select v.id into el_vecino from public.productos p
      join public.productos v on v.categoria_id = p.categoria_id and v.activo and v.id <> p.id
     where p.id = el_id
       and case when direccion = 'arriba' then v.orden < p.orden else v.orden > p.orden end
     order by case when direccion = 'arriba' then -v.orden else v.orden end
     limit 1;
  end if;
  return el_vecino;
end

  end if;
```

```sql
  returning id into el_aumento;
  update public.precios pr set monto_centavos = (r ->> 'despues_centavos')::bigint
    from jsonb_array_elements(datos -> 'precios') r
   where pr.id = (r ->> 'id')::uuid;
  return el_aumento;
```

```sql
with (security_invoker = false)
as

       c.nombre as categoria,
       c.subtitulo,
       c.foto,
       c.icono,
       c.orden as orden_categoria,
       comun.lista as compartidos,

  cross join lateral (
    select coalesce(
             jsonb_agg(jsonb_build_object('presentacion', pre.nombre, 'monto_centavos', pr.monto_centavos)
                       order by pre.orden, pre.id),
             '[]'::jsonb) as lista

     where pre.categoria_id = c.id and pre.activo
  ) comun

    select jsonb_agg(jsonb_build_object(
             'presentacion', pre.nombre,

        on compartido.presentacion_id = pre.id and compartido.producto_id is null and compartido.activo
     where pre.categoria_id = c.id and pre.activo
  ) vigentes

   -- El local principal. Con un segundo local se suma el filtro por dominio.
   and c.local_id = (select l.id from public.locales l order by l.fecha_creacion, l.id limit 1);
```

```sql
declare

begin
  insert into public.presentaciones (local_id, categoria_id, nombre, orden)
```

```ts
/** Un monto en pesos enteros como lo ve el publico del menu: $4.000. */
export function formatearPesosEnteros(centavos: number): string {
  if (!Number.isSafeInteger(centavos) || centavos % 100 !== 0) {
    throw new Error(`Un precio del menu tiene que ser de pesos enteros y llegó: ${centavos}`);
  }
  const pesos = String(Math.abs(centavos) / 100).replace(/\B(?=(\d{3})+(?!\d))/g, '.');
  return `${centavos < 0 ? '-' : ''}$${pesos}`;
}
```

```ts
export type PrecioGuardado = { presentacionId: string; productoId: string | null; montoCentavos: number };
export type PresentacionDelMenu = { id: string; nombre: string };
export type OrigenDelPrecio = 'propio' | 'compartido';
export type PrecioVigente = {
  presentacionId: string;
  presentacion: string;
  montoCentavos: number | null;
  origen: OrigenDelPrecio | null;
};

function vigenteEn(
  productoId: string,
  presentacion: PresentacionDelMenu,
  precios: PrecioGuardado[],
): PrecioVigente {
  const deLaPresentacion = precios.filter((p) => p.presentacionId === presentacion.id);
  const propio = deLaPresentacion.find((p) => p.productoId === productoId);
  const compartido = deLaPresentacion.find((p) => p.productoId === null);
  const origen = propio ? 'propio' : compartido ? 'compartido' : null;
  const montoCentavos = (propio ?? compartido)?.montoCentavos ?? null;
  return { presentacionId: presentacion.id, presentacion: presentacion.nombre, montoCentavos, origen };
}

/**
 * El precio de cada presentacion: el propio del producto si lo tiene; si no, el compartido de
 * la categoria. La misma regla que usa la base. Recibe solo precios y presentaciones activos.
 */
export function preciosVigentes(
  productoId: string,
  presentaciones: PresentacionDelMenu[],
  precios: PrecioGuardado[],
): PrecioVigente[] {
  return presentaciones.map((presentacion) => vigenteEn(productoId, presentacion, precios));
}

export function tienePrecio(vigentes: PrecioVigente[]): boolean {
  return vigentes.some((vigente) => vigente.montoCentavos !== null);
}
```

```ts
export const REDONDEOS_CENTAVOS = [1000, 5000, 10000, 50000] as const;
export type RedondeoCentavos = (typeof REDONDEOS_CENTAVOS)[number];
export const REDONDEO_POR_DEFECTO: RedondeoCentavos = 10000;
export const PORCENTAJE_MINIMO = -50;
export const PORCENTAJE_MAXIMO = 200;

export type PrecioDelAlcance = {
  id: string;
  categoria: string;
  // null: el precio compartido de la categoria.
  producto: string | null;
  presentacion: string;
  montoCentavos: number;
  oculto: boolean;
};
export type CambioDePrecio = PrecioDelAlcance & { nuevoCentavos: number };

/**
 * El precio con el porcentaje aplicado, redondeado al paso mas cercano (la mitad, para
 * arriba). Nunca baja de un paso: un descuento no deja un precio en cero. En BigInt para no
 * pasar por punto flotante.
 */
export function precioAumentado(
  montoCentavos: number,
  porcentaje: number,
  redondeoCentavos: RedondeoCentavos,
): number {
  const numerador = BigInt(montoCentavos) * BigInt(100 + porcentaje);
  const divisor = BigInt(100 * redondeoCentavos);
  const pasos = numerador / divisor + ((numerador % divisor) * 2n >= divisor ? 1n : 0n);
  return Number(pasos < 1n ? 1n : pasos) * redondeoCentavos;
}

export function vistaPrevia(
  precios: PrecioDelAlcance[],
  porcentaje: number,
  redondeoCentavos: RedondeoCentavos,
): CambioDePrecio[] {
  return precios.map((precio) => ({
    ...precio,
    nuevoCentavos: precioAumentado(precio.montoCentavos, porcentaje, redondeoCentavos),
  }));
}
```

```ts
/** Las fotos de la carga inicial viven en public/menu; las que sube el admin, en el bucket. */
export function urlDeFoto(foto: string | null, urlDeSupabase: string): string | null {
  if (!foto) return null;
  if (foto.startsWith('/')) return foto;
  return `${urlDeSupabase}/storage/v1/object/public/${BUCKET_DE_FOTOS}/${foto}`;

export function esTipoDeFoto(tipo: string): tipo is TipoDeFoto {
  return tipo in EXTENSIONES;

  if (bytes > TAMANIO_MAXIMO_DE_FOTO) return 'La foto pesa más de 10 MB. Probá con una más chica.';

}
```

```ts
import { z } from 'zod';
import { formatearPesosEnteros } from '../plata';

const esquemaFila = z.object({
  categoria_id: z.string(),
  categoria: z.string(),
  subtitulo: z.string().nullable(),
  foto: z.string().nullable(),
  icono: z.string(),
  orden_categoria: z.number(),
  compartidos: z.array(z.object({ presentacion: z.string(), monto_centavos: z.number() })),
  producto_id: z.string(),
  nombre: z.string(),
  descripcion: z.string().nullable(),
  etiqueta: z.enum(['mas_vendido', 'artesanal', 'nuevo']).nullable(),
  orden: z.number(),
  precios: z.array(
    z.object({ presentacion: z.string(), monto_centavos: z.number().nullable(), compartido: z.boolean() }),
  ),
});

export type FilaPublica = z.infer<typeof esquemaFila>;
export type PrecioPublico = { etiqueta: string | null; texto: string };
export type ProductoPublico = {
  id: string;
  nombre: string;
  descripcion: string | null;
  etiqueta: string | null;
  precios: PrecioPublico[];
};
export type CategoriaPublica = {
  id: string;
  ancla: string;
  nombre: string;
  icono: string;
  foto: string | null;
  subtitulo: string | null;
  columnas: 1 | 2;
  encabezados: string[] | null;
  productos: ProductoPublico[];
};

export const TEXTOS_DE_ETIQUETA = {
  mas_vendido: '🔥 Más vendido',
  artesanal: 'Artesanal',
  nuevo: 'Nuevo',
} as const;

/** Las filas de menu_publico, comprobadas: los JSON de la vista llegan sin tipo. */
export function leerFilas(datos: unknown): FilaPublica[] {
  return z.array(esquemaFila).parse(datos);
}

const textoDe = (monto: number | null) => (monto === null ? '—' : formatearPesosEnteros(monto));

function subtituloDe(fila: FilaPublica): string | null {
  const precios = fila.compartidos.map((c) => `${c.presentacion} ${formatearPesosEnteros(c.monto_centavos)}`);
  const partes = [...precios, ...(fila.subtitulo ? [fila.subtitulo] : [])];
  return partes.length > 0 ? partes.join(' · ') : null;
}

// Una columna por presentacion cuando hay varias y ninguna tiene precio compartido.
function encabezadosDe(fila: FilaPublica): string[] | null {
  if (fila.precios.length < 2 || fila.compartidos.length > 0) return null;
  return fila.precios.map((p) => p.presentacion);
}

function preciosDe(fila: FilaPublica, encabezados: string[] | null): PrecioPublico[] {
  if (encabezados) return fila.precios.map((p) => ({ etiqueta: p.presentacion, texto: textoDe(p.monto_centavos) }));
  // El heredado ya esta en el subtitulo: el producto muestra solo los suyos.
  const propios = fila.precios.filter((p) => !p.compartido && p.monto_centavos !== null);
  const conEtiqueta = fila.precios.length > 1;
  return propios.map((p) => ({ etiqueta: conEtiqueta ? p.presentacion : null, texto: textoDe(p.monto_centavos) }));
}

function productoDe(fila: FilaPublica, encabezados: string[] | null): ProductoPublico {
  return {
    id: fila.producto_id,
    nombre: fila.nombre,
    descripcion: fila.descripcion,
    etiqueta: fila.etiqueta ? TEXTOS_DE_ETIQUETA[fila.etiqueta] : null,
    precios: preciosDe(fila, encabezados),
  };
}

function anclaDe(nombre: string, usadas: Set<string>): string {
  const base = nombre.normalize('NFD').replace(/[̀-ͯ]/g, '').toLowerCase()
    .replace(/[^a-z0-9]+/g, '-').replace(/^-|-$/g, '') || 'categoria';
  let ancla = base;
  for (let n = 2; usadas.has(ancla); n += 1) ancla = `${base}-${n}`;
  usadas.add(ancla);
  return ancla;
}

function categoriaDe(filas: FilaPublica[], usadas: Set<string>): CategoriaPublica {
  const [primera] = filas;
  const encabezados = encabezadosDe(primera);
  return {
    id: primera.categoria_id,
    ancla: anclaDe(primera.categoria, usadas),
    nombre: primera.categoria,
    icono: primera.icono,
    foto: primera.foto,
    subtitulo: subtituloDe(primera),
    columnas: encabezados ? 1 : 2,
    encabezados,
    productos: filas.map((fila) => productoDe(fila, encabezados)),
  };
}

const enOrden = (a: FilaPublica, b: FilaPublica) =>
  a.orden_categoria - b.orden_categoria || a.categoria_id.localeCompare(b.categoria_id) ||
  a.orden - b.orden || a.producto_id.localeCompare(b.producto_id);

/** El menu agrupado por categoria, en el orden que eligio el admin. */
export function menuPublico(filas: FilaPublica[]): CategoriaPublica[] {
  const grupos = new Map<string, FilaPublica[]>();
  for (const fila of [...filas].sort(enOrden)) {
    grupos.set(fila.categoria_id, [...(grupos.get(fila.categoria_id) ?? []), fila]);
  }
  const usadas = new Set<string>();
  return [...grupos.values()].map((grupo) => categoriaDe(grupo, usadas));
}
```

```ts
import type { PrecioDelAlcance } from './aumento';
import type { DatosDeCategoria, DatosDeProducto } from './esquemas';
import type { Icono } from './iconos';
import {
  preciosVigentes,
  tienePrecio,
  type PrecioGuardado,
  type PrecioVigente,
  type PresentacionDelMenu,
} from './precios';

export type Etiqueta = 'mas_vendido' | 'artesanal' | 'nuevo';
export type FilaCategoria = {
  id: string; nombre: string; subtitulo: string | null; foto: string | null; icono: string;
  orden: number; visible: boolean; activo: boolean;
};
export type FilaPresentacion = { id: string; categoria_id: string; nombre: string; orden: number; activo: boolean };
export type FilaProducto = {
  id: string; categoria_id: string; nombre: string; descripcion: string | null;
  etiqueta: Etiqueta | null; orden: number; visible: boolean; activo: boolean;
};
export type FilaPrecio = {
  id: string; presentacion_id: string; producto_id: string | null; monto_centavos: number; activo: boolean;
};
export type FilasDelMenu = {
  categorias: FilaCategoria[];
  presentaciones: FilaPresentacion[];
  productos: FilaProducto[];
  precios: FilaPrecio[];
};
export type ProductoDelPanel = {
  id: string; nombre: string; descripcion: string | null; etiqueta: Etiqueta | null;
  visible: boolean; precios: PrecioVigente[]; conPrecio: boolean;
};
export type CategoriaDelPanel = {
  id: string; nombre: string; subtitulo: string | null; foto: string | null; icono: Icono;
  visible: boolean; presentaciones: PresentacionDelMenu[]; compartidos: (number | null)[];
  productos: ProductoDelPanel[];
};
export type Desactivados = {
  categorias: { id: string; nombre: string }[];
  productos: { id: string; nombre: string; categoria: string; categoriaActiva: boolean }[];
};

const porOrden = <T extends { orden: number; id: string }>(a: T, b: T) =>
  a.orden - b.orden || a.id.localeCompare(b.id);

function presentacionesDe(filas: FilasDelMenu, categoriaId: string): PresentacionDelMenu[] {
  return filas.presentaciones
    .filter((p) => p.categoria_id === categoriaId && p.activo)
    .sort(porOrden)
    .map(({ id, nombre }) => ({ id, nombre }));
}

function preciosGuardados(filas: FilasDelMenu): PrecioGuardado[] {
  return filas.precios
    .filter((p) => p.activo)
    .map((p) => ({ presentacionId: p.presentacion_id, productoId: p.producto_id, montoCentavos: p.monto_centavos }));
}

function productoDelPanel(fila: FilaProducto, presentaciones: PresentacionDelMenu[], precios: PrecioGuardado[]) {
  const vigentes = preciosVigentes(fila.id, presentaciones, precios);
  const { id, nombre, descripcion, etiqueta, visible } = fila;
  return { id, nombre, descripcion, etiqueta, visible, precios: vigentes, conPrecio: tienePrecio(vigentes) };
}

function categoriaDelPanel(fila: FilaCategoria, filas: FilasDelMenu, precios: PrecioGuardado[]): CategoriaDelPanel {
  const presentaciones = presentacionesDe(filas, fila.id);
  const compartido = (p: PresentacionDelMenu) =>
    precios.find((x) => x.presentacionId === p.id && x.productoId === null)?.montoCentavos ?? null;
  const productos = filas.productos
    .filter((p) => p.categoria_id === fila.id && p.activo)
    .sort(porOrden)
    .map((p) => productoDelPanel(p, presentaciones, precios));
  const { id, nombre, subtitulo, foto, visible } = fila;
  return { id, nombre, subtitulo, foto, icono: fila.icono as Icono, visible, presentaciones,
    compartidos: presentaciones.map(compartido), productos };
}

/** Las categorias y productos activos, en el orden del menu, con el precio vigente de cada uno. */
export function armarPanel(filas: FilasDelMenu): CategoriaDelPanel[] {
  const precios = preciosGuardados(filas);
  return filas.categorias
    .filter((c) => c.activo)
    .sort(porOrden)
    .map((c) => categoriaDelPanel(c, filas, precios));
}

function alcanceDeCategoria(categoria: CategoriaDelPanel, filas: FilasDelMenu): PrecioDelAlcance[] {
  const ids = new Set(categoria.presentaciones.map((p) => p.id));
  const productos = new Map(categoria.productos.map((p) => [p.id, p]));
  const presentacion = (id: string) => categoria.presentaciones.find((p) => p.id === id)!.nombre;
  return filas.precios
    .filter((p) => p.activo && ids.has(p.presentacion_id) && (p.producto_id === null || productos.has(p.producto_id)))
    .map((p) => ({
      id: p.id, categoria: categoria.nombre, presentacion: presentacion(p.presentacion_id),
      producto: p.producto_id ? productos.get(p.producto_id)!.nombre : null,
      oculto: p.producto_id ? !productos.get(p.producto_id)!.visible : false, montoCentavos: p.monto_centavos,
    }));
}

/** Los precios que toca un aumento: los mismos que comprueba la base al aplicarlo. */
export function alcanceDelAumento(filas: FilasDelMenu, categoriaId: string | null): PrecioDelAlcance[] {
  return armarPanel(filas)
    .filter((c) => categoriaId === null || c.id === categoriaId)
    .flatMap((c) => alcanceDeCategoria(c, filas));
}

export function desactivados(filas: FilasDelMenu): Desactivados {
  const categorias = new Map(filas.categorias.map((c) => [c.id, c]));
  return {
    categorias: filas.categorias.filter((c) => !c.activo).sort(porOrden).map(({ id, nombre }) => ({ id, nombre })),
    productos: filas.productos.filter((p) => !p.activo).sort(porOrden).map((p) => ({
      id: p.id, nombre: p.nombre,
      categoria: categorias.get(p.categoria_id)?.nombre ?? '', categoriaActiva: categorias.get(p.categoria_id)?.activo ?? false,
    })),
  };
}

const enPesos = (centavos: number | null) => (centavos === null ? '' : String(centavos / 100));

export function categoriaParaEditar(panel: CategoriaDelPanel[], id: string): DatosDeCategoria | null {
  const categoria = panel.find((c) => c.id === id);
  if (!categoria) return null;
  return {
    id: categoria.id, nombre: categoria.nombre, subtitulo: categoria.subtitulo ?? '',
    icono: categoria.icono, foto: categoria.foto ?? '',
    precioCompartido: categoria.compartidos.some((c) => c !== null),
    presentaciones: categoria.presentaciones.map((p, i) => ({ id: p.id, nombre: p.nombre, compartido: enPesos(categoria.compartidos[i]) })),
  };
}

export function productoParaEditar(panel: CategoriaDelPanel[], id: string): DatosDeProducto | null {
  for (const categoria of panel) {
    const producto = categoria.productos.find((p) => p.id === id);
    if (!producto) continue;
    return {
      id: producto.id, categoriaId: categoria.id, nombre: producto.nombre,
      descripcion: producto.descripcion ?? '', etiqueta: producto.etiqueta ?? '', visible: producto.visible,
      precios: producto.precios.map((p) => ({
        presentacionId: p.presentacionId, monto: p.origen === 'propio' ? enPesos(p.montoCentavos) : '' })),
    };
  }
  return null;
}
```

```ts
  const [categorias, presentaciones, productos, precios] = await Promise.all([
    cliente.from('categorias').select('id, nombre, subtitulo, foto, icono, orden, visible, activo'),
    cliente.from('presentaciones').select('id, categoria_id, nombre, orden, activo'),
    cliente.from('productos').select('id, categoria_id, nombre, descripcion, etiqueta, orden, visible, activo'),
    cliente.from('precios').select('id, presentacion_id, producto_id, monto_centavos, activo'),
  ]);
  return {
    categorias: datosDe(categorias, 'las categorias'),
    presentaciones: datosDe(presentaciones, 'las presentaciones'),
    productos: datosDe(productos, 'los productos'),
    precios: datosDe(precios, 'los precios'),
  };
}
```

```ts
import { exito, fallo, type Resultado } from '../resultado';
import type { Cliente } from '../supabase/cliente';
import { precioAumentado, type RedondeoCentavos } from './aumento';
import { mensajeDelMenu, nombresDelDetalle, type ErrorDeLaBase } from './errores';
import {
  categoriaParaLaBase,
  productoParaLaBase,
  type DatosDeAplicarAumento,
  type DatosDeCategoria,
  type DatosDeProducto,
  type ElementoDelMenu,
} from './esquemas';

export type Guardado =
  | { estado: 'guardado'; id: string; ocultados: string[] }
  | { estado: 'confirmar'; productos: string[] };

type RespuestaDeGuardado = { data: unknown; error: (ErrorDeLaBase & object) | null };

// PM101 no es un error para la persona: es la pregunta "¿los oculto?".
function guardadoDe({ data, error }: RespuestaDeGuardado): Resultado<Guardado> {
  if (error?.code === 'PM101') return exito({ estado: 'confirmar', productos: nombresDelDetalle(error) });
  if (error) return fallo(mensajeDelMenu(error));
  const { id, ocultados } = data as { id: string; ocultados: string[] };
  return exito({ estado: 'guardado', id, ocultados });
}

function resultadoDe(error: ErrorDeLaBase): Resultado {
  return error ? fallo(mensajeDelMenu(error)) : exito(undefined);
}

export async function guardarCategoria(cliente: Cliente, datos: DatosDeCategoria, confirmar: boolean) {
  return guardadoDe(await cliente.rpc('menu_guardar_categoria', { datos: categoriaParaLaBase(datos), confirmar }));
}

export async function guardarProducto(cliente: Cliente, datos: DatosDeProducto, confirmar: boolean) {
  return guardadoDe(await cliente.rpc('menu_guardar_producto', { datos: productoParaLaBase(datos), confirmar }));
}

export async function cambiarVisibilidad(cliente: Cliente, { tipo, id, mostrar }: ElementoDelMenu & { mostrar: boolean }) {
  const { error } = await cliente.rpc('menu_cambiar_visibilidad', { el_tipo: tipo, el_id: id, mostrar });
  return resultadoDe(error);
}

export async function mover(cliente: Cliente, { tipo, id, direccion }: ElementoDelMenu & { direccion: 'arriba' | 'abajo' }) {
  const { error } = await cliente.rpc('menu_mover', { el_tipo: tipo, el_id: id, direccion });
  return resultadoDe(error);
}

export async function desactivar(cliente: Cliente, { tipo, id }: ElementoDelMenu) {
  return resultadoDe((await cliente.rpc('menu_desactivar', { el_tipo: tipo, el_id: id })).error);
}

export async function reactivar(cliente: Cliente, { tipo, id }: ElementoDelMenu) {
  return resultadoDe((await cliente.rpc('menu_reactivar', { el_tipo: tipo, el_id: id })).error);
}

/** El precio nuevo lo calcula el servidor; del navegador llega solo el precio que se vio antes. */
export async function aplicarAumento(cliente: Cliente, datos: DatosDeAplicarAumento): Promise<Resultado<{ cantidad: number }>> {
  const porcentaje = Number(datos.porcentaje);
  const redondeo = Number(datos.redondeo) as RedondeoCentavos;
  const precios = datos.precios.map((p) => ({
    id: p.id, antes_centavos: p.antesCentavos, despues_centavos: precioAumentado(p.antesCentavos, porcentaje, redondeo),
  }));
  const aumento = { porcentaje, redondeo_centavos: redondeo, categoria_id: datos.categoriaId || null, precios };
  const { error } = await cliente.rpc('menu_aplicar_aumento', { datos: aumento });
  return error ? fallo(mensajeDelMenu(error)) : exito({ cantidad: precios.length });
}
```

```ts
import { exito, fallo, type Resultado } from '../resultado';
import type { Cliente } from '../supabase/cliente';
import { BUCKET_DE_FOTOS, esTipoDeFoto, problemaDeFoto, rutaDeFoto } from './fotos';

/** Sube la foto con la sesion de quien la elige, directo a Storage: no pasa por el servidor. */
export async function subirFoto(cliente: Cliente, localId: string, archivo: File): Promise<Resultado<string>> {
  const problema = problemaDeFoto(archivo.type, archivo.size);
  if (problema || !esTipoDeFoto(archivo.type)) return fallo(problema ?? 'Subí una foto JPG, PNG o WebP.');
  const ruta = rutaDeFoto(localId, archivo.type, crypto.randomUUID());
  const { error } = await cliente.storage.from(BUCKET_DE_FOTOS).upload(ruta, archivo, { contentType: archivo.type });
  return error ? fallo('No pudimos subir la foto. Probá de nuevo.') : exito(ruta);
}
```

```ts
import { useEffect, useRef } from 'react';

/** Muestra el elemento con una animacion la primera vez que entra en pantalla. */
export function useAparecer<T extends HTMLElement>() {
  const ref = useRef<T>(null);
  useEffect(() => {
    const elemento = ref.current;
    if (!elemento) return;
    const observador = new IntersectionObserver(
      (entradas) => entradas.forEach((e) => e.isIntersecting && e.target.classList.add('visible')),
      { threshold: 0.1, rootMargin: '0px 0px -40px 0px' },
    );
    observador.observe(elemento);
    return () => observador.disconnect();
  }, []);
```

`src/lib/menu/useCategoriaActiva.ts`:

```ts
import { useEffect, useState } from 'react';

/** La categoria que se esta mirando y si la pagina esta arriba de todo, para la navegacion. */
export function useCategoriaActiva(anclas: string[]) {
  const [activa, setActiva] = useState(anclas[0] ?? '');
  const [arriba, setArriba] = useState(true);
  useEffect(() => {
    const alScrollear = () => setArriba(window.scrollY < 100);
    window.addEventListener('scroll', alScrollear, { passive: true });
    const observador = new IntersectionObserver(
      (entradas) => entradas.forEach((e) => e.isIntersecting && setActiva(e.target.id)),
      { rootMargin: '-20% 0px -70% 0px' },
    );
    anclas.forEach((ancla) => {
      const seccion = document.getElementById(ancla);
      if (seccion) observador.observe(seccion);
    });
    return () => {
      window.removeEventListener('scroll', alScrollear);
      observador.disconnect();
    };
  }, [anclas]);
  return { activa, arriba };
}
```

```ts
function textoDe(precio: PrecioVigente, categoria: string): string {
  if (precio.montoCentavos === null) return `${precio.presentacion} sin precio`;
```

```ts
import { useState } from 'react';
import type { Resultado } from '../resultado';

/** Corre una accion del menu y guarda el mensaje si no se pudo. */
export function useAccionDelMenu() {
  const [mensaje, setMensaje] = useState<string | null>(null);
  const [enviando, setEnviando] = useState(false);
  async function hacer(accion: () => Promise<Resultado<unknown>>): Promise<boolean> {
    setEnviando(true);
    setMensaje(null);
    const resultado = await accion();
    setEnviando(false);
    if (!resultado.ok) setMensaje(resultado.mensaje);
    return resultado.ok;
  }
  return { mensaje, enviando, hacer };
}
```

```tsx
import Link from 'next/link';
import { useState } from 'react';
import { AvisoDeError } from '@/components/formularios/AvisoDeError';

type Props = { tipo: 'categoria' | 'producto'; id: string; nombre: string; visible: boolean; editar: string };

export function BotonesDeElemento({ tipo, id, nombre, visible, editar }: Props) {
  const { mensaje, enviando, hacer } = useAccionDelMenu();
  const [confirmando, setConfirmando] = useState(false);
  const mover = (direccion: 'arriba' | 'abajo') => hacer(() => moverEnElMenu({ tipo, id, direccion }));
  return (

      <div className="flex flex-wrap gap-2">
        <Button variant="outline" size="sm" disabled={enviando} aria-label={`Subir ${nombre}`} onClick={() => mover('arriba')}>↑</Button>
        <Button variant="outline" size="sm" disabled={enviando} aria-label={`Bajar ${nombre}`} onClick={() => mover('abajo')}>↓</Button>
        <Button variant="outline" size="sm" disabled={enviando} aria-label={`${visible ? 'Ocultar' : 'Mostrar'} ${nombre}`}
          onClick={() => hacer(() => cambiarVisibilidadEnElMenu({ tipo, id, mostrar: !visible }))}>
          {visible ? 'Ocultar' : 'Mostrar'}
        </Button>
        <Button asChild variant="outline" size="sm"><Link href={editar} aria-label={`Editar ${nombre}`}>Editar</Link></Button>
        <Button variant="outline" size="sm" disabled={enviando} aria-label={`Desactivar ${nombre}`} onClick={() => setConfirmando(true)}>Desactivar</Button>
      </div>
      {confirmando ? (
        <div className="space-y-2 rounded-lg border p-3">
          <p className="text-sm">{PREGUNTA_DE_DESACTIVAR(nombre)}</p>
          <div className="flex gap-2">
            <Button variant="destructive" disabled={enviando}
              onClick={async () => setConfirmando(!(await hacer(() => desactivarEnElMenu({ tipo, id }))) && false)}>Confirmar</Button>
            <Button variant="outline" onClick={() => setConfirmando(false)}>Cancelar</Button>
          </div>
        </div>
      ) : null}
      {mensaje ? <AvisoDeError mensaje={mensaje} /> : null}
    </div>
  );
```

```ts
import { useState } from 'react';
import type { Resultado } from '../resultado';
import type { Guardado } from './escritura';

/**
 * Guarda y, si la base avisa que el cambio oculta productos, guarda la lista para preguntar.
 * Confirmar repite el mismo guardado con la confirmacion.
 */
export function useGuardado<T>(
  accion: (datos: T & { confirmar: boolean }) => Promise<Resultado<Guardado>>,
  alGuardar: () => void,
) {
  const [mensaje, setMensaje] = useState<string | null>(null);
  const [pendiente, setPendiente] = useState<{ datos: T; productos: string[] } | null>(null);
  async function guardar(datos: T, confirmar: boolean) {
    setMensaje(null);
    const resultado = await accion({ ...datos, confirmar });
    if (!resultado.ok) return setMensaje(resultado.mensaje);
    if (resultado.datos.estado === 'confirmar') return setPendiente({ datos, productos: resultado.datos.productos });
    setPendiente(null);
    alGuardar();
  }
  return {
    mensaje,
    pendiente: pendiente?.productos ?? null,
    enviar: (datos: T) => guardar(datos, false),
    confirmar: async () => (pendiente ? guardar(pendiente.datos, true) : undefined),
    cancelar: () => setPendiente(null),
  };
}
```

```ts
import { useEffect } from 'react';
import { useFormContext, useWatch } from 'react-hook-form';
import type { DatosDeProducto } from './esquemas';
import type { PresentacionDelMenu } from './precios';

export type OpcionDeCategoria = {
  id: string;
  nombre: string;
  presentaciones: PresentacionDelMenu[];
  compartidos: (number | null)[];
};

/**
 * Los precios del formulario siguen a la categoria elegida: si cambia, se piden los de sus
 * presentaciones, vacios. Al editar, la categoria de arranque conserva los cargados.
 */
export function usePreciosSegunCategoria(opciones: OpcionDeCategoria[]) {
  const { control, getValues, setValue } = useFormContext<DatosDeProducto>();
  const categoriaId = useWatch({ control, name: 'categoriaId' });
  const categoria = opciones.find((o) => o.id === categoriaId);
  useEffect(() => {
    const ids = (categoria?.presentaciones ?? []).map((p) => p.id);
    const actuales = getValues('precios').map((p) => p.presentacionId);
    if (ids.join() === actuales.join()) return;
    setValue('precios', ids.map((presentacionId) => ({ presentacionId, monto: '' })));
  }, [categoria, getValues, setValue]);
  return categoria;
}
```

```ts
import { useState } from 'react';
import type { Resultado } from '../resultado';
import type { CambioDePrecio } from './aumento';
import type { DatosDeAplicarAumento, DatosDeAumento } from './esquemas';

type Acciones = {
  ver: (datos: DatosDeAumento) => Promise<Resultado<CambioDePrecio[]>>;
  aplicar: (datos: DatosDeAplicarAumento) => Promise<Resultado<{ cantidad: number }>>;
};

/** La vista previa y su aplicacion: se aplica exactamente lo que se vio. */
export function useAumento(acciones: Acciones) {
  const [vista, setVista] = useState<{ datos: DatosDeAumento; cambios: CambioDePrecio[] } | null>(null);
  const [mensaje, setMensaje] = useState<string | null>(null);
  const [listo, setListo] = useState<string | null>(null);
  async function ver(datos: DatosDeAumento) {
    setMensaje(null);
    setListo(null);
    const resultado = await acciones.ver(datos);
    if (resultado.ok) setVista({ datos, cambios: resultado.datos });
    else setMensaje(resultado.mensaje);
  }
  async function aplicar() {
    if (!vista) return;
    const precios = vista.cambios.map((c) => ({ id: c.id, antesCentavos: c.montoCentavos }));
    const resultado = await acciones.aplicar({ ...vista.datos, precios });
    if (!resultado.ok) return setMensaje(resultado.mensaje);
    setVista(null);
    setListo(`Listo: se actualizaron ${resultado.datos.cantidad} precios.`);
  }
  return { cambios: vista?.cambios ?? null, mensaje, listo, ver, aplicar, descartar: () => setVista(null) };
}
```
