# Usuarios y acceso: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que cada persona entre con su cuenta, vea solo lo que le toca y que todo lo que cambie quede a su nombre, con el mecanismo de auditoría que van a usar todos los módulos.

**Architecture:** Los roles viven en `perfiles`, una fila por cuenta de Supabase Auth. La base hace cumplir las reglas con RLS, triggers y funciones (primera cuenta admin, nadie se baja a sí mismo, nunca cero admins, auditoría genérica). Antes de cambiar con la clave secreta la contraseña o el email de una cuenta, el servidor anota la acción en `acciones_de_cuenta`: así la base sabe quién lo pidió. Next.js 16 maneja la sesión con `@supabase/ssr` desde `proxy.ts`. El servidor decide el acceso con una función pura sobre el perfil, y las acciones validan con Zod y llaman a servicios que reciben el cliente por parámetro.

**Tech Stack:** Next.js 16.4 (App Router), React 19, TypeScript, Supabase (`@supabase/supabase-js` 2.117.2, `@supabase/ssr` 0.12.7), Zod 4, React Hook Form 7.89 con `@hookform/resolvers` 5.9, Tailwind 4, shadcn/ui, Vitest 5, Playwright 1.63.

**Spec:** `docs/superpowers/specs/2026-10-07-usuarios-design.md`. La definición funcional está en `docs/modulos/01-usuarios.md`.

## Global Constraints

- **Quién decide:** solo Santiago autoriza aplicar una migración a la base real, publicar en producción y cualquier excepción a las reglas. Este plan aplica la migración solo a la base de pruebas.
- **TDD:** primero el test, verlo fallar y commitearlo; después el código, verlo pasar y commitearlo. Código escrito antes que su test se borra y se rehace.
- **Tests sin mocks:** contra la base de pruebas. Nada de `vi.mock`, `vi.fn` como reemplazo, `page.route` ni clientes falsos. La fecha y el azar entran como parámetro.
- **Hecho es probado en local:** `npm run verificar` y `npm run e2e`, los dos.
- **Largo:** 20 líneas por función en `.ts`, 80 por componente en `.tsx`, 300 por archivo, sin blancos ni comentarios. La lógica no vive en los `.tsx`. Si el lint falla por largo, se divide el código.
- **Idioma:** nombres, comentarios, base y mensajes en español; pantallas en rioplatense con voseo. Un comentario explica el porqué. La cabecera de una migración va sin tildes.
- **Datos y seguridad:** cada operación con la sesión del usuario y RLS. El usuario y el local salen de la sesión. Nada se borra: se desactiva. Toda escritura deja auditoría. La clave secreta solo desde `src/lib/supabase/secreto.ts`, y en la aplicación solo después de comprobar que lo pide un admin activo.
- **Guía de estilos:** ninguna pantalla define colores, tipografías ni medidas sueltas; todo cambio estético va a la guía y su página.
- **Bases:** migraciones y consultas con el servidor MCP `supabase-pruebas`. Nunca el servidor `supabase` general, y `supabase-real` no se toca.
- **Versiones exactas:** todo se instala con `--save-exact`; `grep -E '"[\^~]' package.json` no devuelve nada.
- **Archivos:** se escriben con las herramientas Write y Edit, nunca con heredocs de Bash (pierden las barras invertidas en esta máquina).
- **Git:** commits chicos en español, cada archivo con su ruta; nunca `git add -A` ni `git add .`. Cada commit termina con `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Rama `feat/usuarios`; a `main` por PR con merge commit y el OK de Santiago.

```ts
export type Rol = 'invitado' | 'caja' | 'encargado' | 'admin';

export type PerfilDeAcceso = {
  id: string;
  nombre: string;
  email: string;
  rol: Rol;
  activo: boolean;
  debe_cambiar_contrasena: boolean;
};

export type EstadoDeAcceso = 'sin-sesion' | 'desactivado' | 'cambiar-contrasena' | Rol;

/** Lo que pide cada pagina: publica (ingreso y registro), panel, cuenta, admin o el cambio obligado. */
export type Pagina = 'publica' | 'panel' | 'cuenta' | 'admin' | 'cambiar-contrasena';

export type EnlaceDelPanel = {
  clave: 'inicio' | 'usuarios' | 'guia' | 'cuenta';
  href: string;
  texto: string;
};

const INGRESAR = '/admin/ingresar';
const PANEL = '/admin';
const RUTAS_ABIERTAS = ['/admin/ingresar', '/admin/registro'];

// Quien entra a cada pagina que exige sesion.
const PERMITIDOS: Record<Exclude<Pagina, 'publica'>, readonly EstadoDeAcceso[]> = {
  panel: ['invitado', 'encargado', 'caja', 'admin'],
  cuenta: ['caja', 'admin'],
  admin: ['admin'],
  'cambiar-contrasena': ['cambiar-contrasena'],
};

const ENLACES: Record<'caja' | 'admin', EnlaceDelPanel[]> = {
  caja: [{ clave: 'cuenta', href: '/admin/cuenta', texto: 'Mi cuenta' }],
  admin: [
    { clave: 'inicio', href: '/admin', texto: 'Inicio' },
    { clave: 'usuarios', href: '/admin/usuarios', texto: 'Usuarios' },
    { clave: 'guia', href: '/admin/guia-de-estilos', texto: 'Guía de estilos' },
    { clave: 'cuenta', href: '/admin/cuenta', texto: 'Mi cuenta' },
  ],
};

export function estadoDeAcceso(perfil: PerfilDeAcceso | null): EstadoDeAcceso {
  if (!perfil) return 'sin-sesion';
  if (!perfil.activo) return 'desactivado';
  if (perfil.debe_cambiar_contrasena) return 'cambiar-contrasena';
  return perfil.rol;
}

/** Adonde mandar a alguien que pide una pagina, o null si puede verla. */
export function destinoDe(estado: EstadoDeAcceso, pagina: Pagina): string | null {
  if (pagina === 'publica') {
    return estado === 'sin-sesion' || estado === 'desactivado' ? null : PANEL;
  }
  if (estado === 'sin-sesion') return INGRESAR;
  if (estado === 'desactivado') return '/admin/salir?motivo=desactivada';
  if (PERMITIDOS[pagina].includes(estado)) return null;
  return estado === 'cambiar-contrasena' ? '/admin/cambiar-contrasena' : PANEL;
}

/** Si una ruta exige sesion. Ingreso y registro quedan abiertos. */
export function requiereSesion(ruta: string): boolean {
  if (RUTAS_ABIERTAS.some((abierta) => ruta === abierta || ruta.startsWith(`${abierta}/`))) {
    return false;
  }
  return ruta === PANEL || ruta.startsWith(`${PANEL}/`);
}

export function enlacesDelPanel(estado: EstadoDeAcceso): EnlaceDelPanel[] {
  return estado === 'caja' || estado === 'admin' ? ENLACES[estado] : [];
}
```

```ts
// Sin caracteres que se confundan al dictarlos: ni 0, O ni o; ni 1, I ni l.
export const ALFABETO_TEMPORAL = 'ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnpqrstuvwxyz23456789';
export const LARGO_TEMPORAL = 12;

/** Una contraseña temporal armada con el azar que recibe: un entero de 32 bits por caracter. */
export function contrasenaTemporal(azar: Uint32Array): string {
  if (azar.length < LARGO_TEMPORAL) {
    throw new Error(`Hacen falta ${LARGO_TEMPORAL} valores al azar.`);
  }
  return Array.from(azar.subarray(0, LARGO_TEMPORAL), (valor) =>
    ALFABETO_TEMPORAL.charAt(valor % ALFABETO_TEMPORAL.length),
  ).join('');
}

/** Una contraseña temporal nueva, con el azar criptografico del sistema. */
export function crearContrasenaTemporal(): string {
  return contrasenaTemporal(crypto.getRandomValues(new Uint32Array(LARGO_TEMPORAL)));
}
```

```ts
export type FilaDeUsuario = Pick<PerfilDeAcceso, 'id' | 'nombre' | 'email' | 'rol' | 'activo'>;

export const POR_PAGINA = 25;

export const OPCIONES_DE_ESTADO: { valor: FiltroDeEstado; texto: string }[] = [
  { valor: 'todos', texto: 'Todos' },
  { valor: 'pendientes', texto: 'Esperando rol' },
  { valor: 'activos', texto: 'Activos' },
  { valor: 'desactivados', texto: 'Desactivados' },
];

export const ETIQUETAS_DE_ACCION: Record<AccionDeUsuario, string> = {
  darCaja: 'Dar rol de Caja',
  darAdmin: 'Dar rol de Admin',
  rechazar: 'Rechazar',
  desactivar: 'Desactivar',
  reactivar: 'Reactivar',
  resetear: 'Resetear contraseña',
  corregir: 'Corregir datos',
};

const NOMBRES_DE_ROL: Record<Rol, string> = {
  invitado: 'Invitado',
  caja: 'Caja',
  encargado: 'Encargado',
  admin: 'Admin',
};

const CAMBIOS_DE_ROL: Record<Rol, AccionDeUsuario[]> = {
  invitado: ['darCaja', 'darAdmin'],
  caja: ['darAdmin'],
  encargado: ['darCaja', 'darAdmin'],
  admin: ['darCaja'],
};

type Cuenta = Pick<PerfilDeAcceso, 'id' | 'rol' | 'activo'>;

export function nombreDeRol(rol: Rol): string {
  return NOMBRES_DE_ROL[rol];
}

/** Como se ve una cuenta en la lista: el invitado rechazado no es una cuenta desactivada. */
export function estadoDeCuenta({ rol, activo }: Cuenta): EstadoDeCuenta {
  if (rol === 'invitado') return activo ? 'Pendiente' : 'Rechazada';
  return activo ? 'Activa' : 'Desactivada';
}

/** Las acciones que ofrece la pantalla. La base y el servidor igual las controlan. */
export function accionesDisponibles(cuenta: Cuenta, yo: string): AccionDeUsuario[] {
  if (cuenta.id === yo) return ['corregir'];
  if (!cuenta.activo) return ['reactivar'];
  if (cuenta.rol === 'invitado') return [...CAMBIOS_DE_ROL.invitado, 'rechazar'];
  return [...CAMBIOS_DE_ROL[cuenta.rol], 'desactivar', 'resetear', 'corregir'];
}

/** El texto de busqueda sin lo que rompe un filtro de PostgREST. Vacio, null. */
export function textoDeBusqueda(texto: string | undefined): string | null {
  const limpio = (texto ?? '').replace(/[,()*%\\:"]/g, ' ').trim().slice(0, 100);
  return limpio === '' ? null : limpio;
}

export function filtroDeEstado(valor: string | undefined): FiltroDeEstado {
  return OPCIONES_DE_ESTADO.find((opcion) => opcion.valor === valor)?.valor ?? 'todos';
}

export function numeroDePagina(valor: string | undefined): number {
  const numero = Number(valor);
  return Number.isSafeInteger(numero) && numero > 0 ? numero : 1;
}

/** De un parametro de la URL que puede venir repetido, el primero. */
export function unValor(valor: string | string[] | undefined): string | undefined {
  return Array.isArray(valor) ? valor[0] : valor;
}

export function cantidadDePaginas(total: number): number {
  return Math.max(1, Math.ceil(total / POR_PAGINA));
}

export function enlaceDeUsuarios({ busqueda, estado, pagina }: FiltrosDeLista): string {
  const parametros = new URLSearchParams();
  if (busqueda) parametros.set('q', busqueda);
  if (estado !== 'todos') parametros.set('estado', estado);
  if (pagina > 1) parametros.set('pagina', String(pagina));
  const consulta = parametros.toString();
  return consulta ? `/admin/usuarios?${consulta}` : '/admin/usuarios';
}

export function textoDePendientes(cantidad: number): string {
  if (cantidad === 0) return 'No hay personas esperando un rol.';
  return cantidad === 1
    ? 'Hay 1 persona esperando un rol.'
    : `Hay ${cantidad} personas esperando un rol.`;
}
```

```ts
    password,
    email_confirm: true,
    app_metadata: { huella_siembra: huellaDe(password) },
```

```ts
  if (anotada.error) throw new Error(`No pude anotar la siembra: ${anotada.error.message}`);
  const { error } = await cliente.auth.admin.updateUserById(cuenta.id, {
    password,
    app_metadata: { huella_siembra: huellaDe(password) },
  });
  if (error) throw new Error(`No pude actualizar la cuenta de prueba ${cuenta.id}: ${error.message}`);
}

async function asegurarCuenta(cliente: Cliente, email: string, password: string, cuenta?: User) {
  if (!cuenta) return { id: await crearCuenta(cliente, email, password), creada: true };
  await asegurarContrasenaDeSiembra(cliente, cuenta, password);
  return { id: cuenta.id, creada: false };
}

async function ajustarPerfil(cliente: Cliente, id: string, deseado: PerfilDePrueba, locales: Locales) {
  const { nombre, rol, activo, otroLocal } = deseado;
  const local_id = otroLocal ? locales.otro : locales.principal;
  const cambios = { nombre, rol, activo, local_id, debe_cambiar_contrasena: false };
  const { error } = await cliente.from('perfiles').update(cambios).eq('id', id);
  if (error) throw new Error(`No pude ajustar el perfil de prueba ${id}: ${error.message}`);
}

/** Crea las cuentas de prueba que falten, actualiza su contraseña y les deja rol, local y estado. */
export async function sembrarCuentas(cliente: Cliente, contrasena: string): Promise<string[]> {
  const cuentas = new Map((await listarCuentas(cliente)).map((c) => [(c.email ?? '').toLowerCase(), c]));
  const locales = { principal: await idDelLocalPrincipal(cliente), otro: await asegurarLocalB(cliente) };
  const creadas: string[] = [];
  // admin primero: el local principal tiene un admin activo antes de tocar al resto.
  const orden = ['admin', ...ROLES_DE_PRUEBA.filter((rol) => rol !== 'admin')] as RolDePrueba[];
  for (const rol of orden) {
    const email = emailDePrueba(rol);
    // listUsers devuelve los emails en minusculas: prueba.adminOtroLocal tiene mayusculas.
    const existente = cuentas.get(email.toLowerCase());
    const { id, creada } = await asegurarCuenta(cliente, email, contrasena, existente);
    await ajustarPerfil(cliente, id, PERFILES_DE_PRUEBA[rol], locales);
    if (creada) creadas.push(email);
  }
  return creadas;
}
```

```sql
create or replace function public.auditar()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
declare
  ignoradas text[] := array_append(tg_argv, 'fecha_actualizacion');
  fila jsonb := to_jsonb(new);
  autor uuid := coalesce(
    (select auth.uid()),
    nullif(current_setting('manteca.usuario', true), '')::uuid
  );
  antes jsonb;
  despues jsonb;
  accion text;
begin
  if tg_op = 'INSERT' then
    despues := fila - ignoradas;
    accion := 'alta';
  else
    select jsonb_object_agg(n.key, o.value), jsonb_object_agg(n.key, n.value)
      into antes, despues
      from jsonb_each(fila) n
      join jsonb_each(to_jsonb(old)) o on o.key = n.key
     where n.value is distinct from o.value
       and not (n.key = any (ignoradas));
    if antes is null then
      return new;
    end if;
    accion := case
      when despues ? 'anulado' and (despues ->> 'anulado')::boolean then 'anulacion'
      when despues ? 'activo' and not (despues ->> 'activo')::boolean then 'desactivacion'
      when despues ? 'activo' then 'reactivacion'
      else 'cambio'
    end;
  end if;
  insert into public.auditoria (local_id, usuario_id, tabla, registro_id, accion, antes, despues, motivo)
  values (
    coalesce(fila ->> 'local_id', case when tg_table_name = 'locales' then fila ->> 'id' end)::uuid,
    autor,
    tg_table_name,
    fila ->> 'id',
    accion,
    antes,
    despues,
    case when accion = 'anulacion' then fila ->> 'motivo_anulacion' end
  );
  return new;
end
$$;

create or replace function public.crear_perfil()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
declare
  cuentas bigint;
begin
  -- Serializa las altas: dos cuentas nuevas a la vez no pueden quedar las dos como admin.
  perform pg_advisory_xact_lock(hashtext('manteca.crear_perfil'));

    lower(new.email),

  );
  perform set_config('manteca.usuario', '', true);

end
$$;

create or replace function public.usar_accion(cuenta uuid, tipos text[], out tipo text, out por uuid)
language plpgsql
security definer
set search_path = ''
as $$
begin
  -- Vale una sola vez y solo si es reciente: una que quedo sin usar no habilita cambios despues.
  update public.acciones_de_cuenta a
     set fecha_uso = now()
   where a.id = (
     select b.id from public.acciones_de_cuenta b
      where b.cuenta_id = cuenta
        and b.tipo = any (tipos)
        and b.fecha_uso is null
        and b.fecha_creacion > now() - interval '10 minutes'
      order by b.fecha_creacion desc
      limit 1
      for update skip locked
   )
  returning a.tipo, a.por into tipo, por;
end
$$;

create or replace function public.registrar_cambio_de_contrasena(cuenta uuid, tipo text, por uuid)
returns void
language plpgsql
security definer
set search_path = ''
as $$
declare
  es_reseteo boolean := coalesce(tipo = 'reseteo', false);
  -- Sin accion anotada la cambio la propia persona. La siembra queda a nombre del sistema.

         case when es_reseteo then 'reseteo_de_contrasena' else 'cambio_de_contrasena' end
    from public.perfiles p
   where p.id = cuenta;
end
$$;

create or replace function public.sincronizar_cuenta()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
declare
  usada record;
begin
  if new.email is distinct from old.email then
    select * into usada from public.usar_accion(new.id, array['correccion']);
    if usada.tipo is null then
      raise exception 'El email de una cuenta lo cambia un administrador' using errcode = 'PM003';
    end if;
    perform set_config('manteca.usuario', coalesce(usada.por::text, ''), true);
    update public.perfiles set email = lower(new.email) where id = new.id;
  end if;
  -- Sin contrasena anterior no es un cambio: es la primera que se pone.
  if new.encrypted_password is distinct from old.encrypted_password
     and coalesce(old.encrypted_password, '') <> '' then
    select * into usada from public.usar_accion(new.id, array['reseteo', 'siembra']);
    perform public.registrar_cambio_de_contrasena(new.id, usada.tipo, usada.por);
  end if;
  perform set_config('manteca.usuario', '', true);
  return new;
end
$$;

create or replace function public.reglas_de_perfiles()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
declare
  otros_admins bigint;
begin
  if (select auth.uid()) = new.id
     and (new.rol is distinct from old.rol or new.activo is distinct from old.activo) then
    raise exception 'No podes cambiar tu propio rol ni desactivarte' using errcode = 'PM001';
  end if;
  if old.rol = 'admin' and old.activo and not (new.rol = 'admin' and new.activo) then
    -- Un bloqueo por local: dos admins que se bajan a la vez no lo dejan sin ninguno.
    perform pg_advisory_xact_lock(hashtext('manteca.admins'), hashtext(old.local_id::text));
    select count(*) into otros_admins
      from public.perfiles
     where local_id = old.local_id and rol = 'admin' and activo and id <> old.id;
    if otros_admins = 0 then
      raise exception 'Tiene que quedar al menos un administrador activo' using errcode = 'PM002';
    end if;
  end if;
  return new;
end
```

```ts
import type { PerfilDeAcceso } from '../acceso/estados';
import type { Cliente } from '../supabase/cliente';
import {
  POR_PAGINA,
  cantidadDePaginas,
  type FilaDeUsuario,
  type FiltroDeEstado,
  type FiltrosDeLista,
} from './presentacion';

export type ListaDeUsuarios = { filas: FilaDeUsuario[]; total: number; pagina: number };

// Cualquier consulta de PostgREST que se pueda filtrar.
type Filtrable<T> = { match(condiciones: Record<string, unknown>): T; or(filtros: string): T };

const COLUMNAS_DEL_PERFIL = 'id, nombre, email, rol, activo, debe_cambiar_contrasena';
const COLUMNAS_DE_LA_LISTA = 'id, nombre, email, rol, activo';

// pendiente es la columna calculada de la base: invitado y activo.
const CONDICIONES_DE_ESTADO: Record<FiltroDeEstado, Record<string, boolean>> = {
  todos: {},
  pendientes: { pendiente: true },
  activos: { activo: true, pendiente: false },
  desactivados: { activo: false },
};

/** El perfil de quien tiene la sesion. Un desactivado tambien lee el suyo: asi se entera. */
export async function perfilPropio(cliente: Cliente): Promise<PerfilDeAcceso | null> {
  const { data: sesion } = await cliente.auth.getClaims();
  const id = sesion?.claims.sub;
  if (!id) return null;
  const { data, error } = await cliente
    .from('perfiles')
    .select(COLUMNAS_DEL_PERFIL)
    .eq('id', id)
    .maybeSingle();
  if (error) throw new Error(`No pudimos leer el perfil: ${error.message}`);
  return data;
}

// Las comillas dejan buscar con espacios; textoDeBusqueda ya saco lo que rompe el filtro.
function filtrar<T extends Filtrable<T>>(consulta: T, { estado, busqueda }: FiltrosDeLista): T {
  const conEstado = consulta.match(CONDICIONES_DE_ESTADO[estado]);
  if (!busqueda) return conEstado;
  return conEstado.or(`nombre.ilike."%${busqueda}%",email.ilike."%${busqueda}%"`);
}

async function contarUsuarios(cliente: Cliente, filtros: FiltrosDeLista): Promise<number> {
  const consulta = cliente.from('perfiles').select('id', { count: 'exact', head: true });
  const { count, error } = await filtrar(consulta, filtros);
  if (error) throw new Error(`No pudimos contar los usuarios: ${error.message}`);
  return count ?? 0;
}

/** Una pagina de la lista, con los que esperan un rol primero. Una pagina de mas va a la ultima. */
export async function listarUsuarios(
  cliente: Cliente,
  filtros: FiltrosDeLista,
): Promise<ListaDeUsuarios> {
  const total = await contarUsuarios(cliente, filtros);
  const pagina = Math.min(filtros.pagina, cantidadDePaginas(total));
  const desde = (pagina - 1) * POR_PAGINA;
  const { data, error } = await filtrar(cliente.from('perfiles').select(COLUMNAS_DE_LA_LISTA), filtros)
    .order('pendiente', { ascending: false })
    .order('nombre')
    .order('id')
    .range(desde, desde + POR_PAGINA - 1);
  if (error) throw new Error(`No pudimos leer los usuarios: ${error.message}`);
  return { filas: data, total, pagina };
}

export function contarPendientes(cliente: Cliente): Promise<number> {
  return contarUsuarios(cliente, { busqueda: null, estado: 'pendientes', pagina: 1 });
}
```

```ts
  if (!error) await aparte.auth.signOut({ scope: 'local' });
  return !error;
}

  return resultadoDe(error);

  cliente: Cliente,
  datos: DatosDeCambioDeContrasena,
): Promise<Resultado> {

  if (!perfil) return fallo(MENSAJES.sesionVencida);
  if (!(await contrasenaCoincide(perfil.email, datos.actual))) {
    return fallo(MENSAJES.actualNoCoincide);
```

```ts
import type { PerfilDeAcceso } from '../acceso/estados';
import { exito, fallo, type Resultado } from '../resultado';
import type { Cliente } from '../supabase/cliente';
import { perfilPropio } from './consultas';
import { crearContrasenaTemporal } from './contrasenas';
import { MENSAJES, mensajeDeError } from './errores';
import type { DatosDeAsignarRol, DatosDeCorreccion } from './esquemas';

export type DatosDeTemporal = { temporal: string; nombre: string };

type Cuenta = Pick<PerfilDeAcceso, 'id' | 'nombre' | 'email'>;
type Contexto = { admin: PerfilDeAcceso; cuenta: Cuenta };
type CambioDePerfil = { rol?: 'caja' | 'admin'; activo?: boolean; nombre?: string };

// Supabase Auth no tiene un bloqueo sin vencimiento: cien años alcanzan.
const BLOQUEO = '876000h';

// Toda accion empieza aca. Sin un admin activo no se sigue, y menos con la clave secreta.
async function prepararAccion(cliente: Cliente, id: string): Promise<Resultado<Contexto>> {
  const admin = await perfilPropio(cliente);
  if (!admin || admin.rol !== 'admin' || !admin.activo) return fallo(MENSAJES.sinPermiso);
  // RLS solo le deja ver las cuentas de su local.
  const { data: cuenta, error } = await cliente
    .from('perfiles')
    .select('id, nombre, email')
    .eq('id', id)
    .maybeSingle();
  if (error) throw new Error(`No pudimos leer la cuenta: ${error.message}`);
  return cuenta ? exito({ admin, cuenta }) : fallo(MENSAJES.cuentaNoEncontrada);
}

async function cambiarPerfil(cliente: Cliente, id: string, cambio: CambioDePerfil): Promise<Resultado> {
  const { error } = await cliente.from('perfiles').update(cambio).eq('id', id);
  return error ? fallo(mensajeDeError(error)) : exito(undefined);
}

async function bloquear(secreto: Cliente, id: string, duracion: string): Promise<Resultado> {
  const { error } = await secreto.auth.admin.updateUserById(id, { ban_duration: duracion });
  return error ? fallo(mensajeDeError(error)) : exito(undefined);
}

// Le avisa a la base que el proximo cambio de contraseña o de email de la cuenta lo pidio este admin.
async function anotarAccion(secreto: Cliente, cuenta: string, tipo: 'reseteo' | 'correccion', por: string) {
  const { error } = await secreto.from('acciones_de_cuenta').insert({ cuenta_id: cuenta, tipo, por });
  if (error) throw new Error(`No pudimos anotar la accion: ${error.message}`);
}

// Con la clave secreta: el email no puede repetirse en ningun local.
async function emailOcupado(secreto: Cliente, email: string): Promise<boolean> {
  const { count, error } = await secreto
    .from('perfiles')
    .select('id', { count: 'exact', head: true })
    .eq('email', email);
  if (error) throw new Error(`No pudimos revisar el email: ${error.message}`);
  return (count ?? 0) > 0;
}

export async function asignarRol(cliente: Cliente, { id, rol }: DatosDeAsignarRol): Promise<Resultado> {
  const previa = await prepararAccion(cliente, id);
  return previa.ok ? cambiarPerfil(cliente, id, { rol }) : previa;
}

/** Desactiva y bloquea en Auth: pierde el acceso aunque tenga la sesion abierta. Rechazar es esto. */
export async function desactivar(cliente: Cliente, secreto: Cliente, id: string): Promise<Resultado> {
  const previa = await prepararAccion(cliente, id);
  if (!previa.ok) return previa;
  // Primero el perfil: la base frena al ultimo admin antes de que se bloquee a nadie.
  const cambio = await cambiarPerfil(cliente, id, { activo: false });
  return cambio.ok ? bloquear(secreto, id, BLOQUEO) : cambio;
}

export async function reactivar(cliente: Cliente, secreto: Cliente, id: string): Promise<Resultado> {
  const previa = await prepararAccion(cliente, id);
  if (!previa.ok) return previa;
  const cambio = await cambiarPerfil(cliente, id, { activo: true });
  return cambio.ok ? bloquear(secreto, id, 'none') : cambio;
}

export async function resetearContrasena(
  cliente: Cliente,
  secreto: Cliente,
  id: string,
): Promise<Resultado<DatosDeTemporal>> {
  const previa = await prepararAccion(cliente, id);
  if (!previa.ok) return previa;
  if (previa.datos.admin.id === id) return fallo(MENSAJES.propiaContrasena);
  await anotarAccion(secreto, id, 'reseteo', previa.datos.admin.id);
  const temporal = crearContrasenaTemporal();
  const { error } = await secreto.auth.admin.updateUserById(id, { password: temporal });
  return error ? fallo(mensajeDeError(error)) : exito({ temporal, nombre: previa.datos.cuenta.nombre });
}

export async function corregir(
  cliente: Cliente,
  secreto: Cliente,
  datos: DatosDeCorreccion,
): Promise<Resultado> {
  const previa = await prepararAccion(cliente, datos.id);
  if (!previa.ok) return previa;
  const cambiaEmail = datos.email !== previa.datos.cuenta.email;
  if (cambiaEmail && (await emailOcupado(secreto, datos.email))) return fallo(MENSAJES.emailExistente);
  const nombre = await cambiarPerfil(cliente, datos.id, { nombre: datos.nombre });
  if (!nombre.ok || !cambiaEmail) return nombre;
  await anotarAccion(secreto, datos.id, 'correccion', previa.datos.admin.id);
  const { error } = await secreto.auth.admin.updateUserById(datos.id, { email: datos.email, email_confirm: true });
  return error ? fallo(mensajeDeError(error)) : exito(undefined);
}
```

```ts
/** El id del mensaje de error de un campo. */
export function idDelError(id: string): string {
  return `${id}-error`;
}

/** Lo que necesita un campo para que el lector de pantalla anuncie su error. */
export function atributosDeError(id: string, error: string | undefined) {
  return error ? { 'aria-invalid': true as const, 'aria-describedby': idDelError(id) } : {};
}

/** El boton que muestra u oculta una contraseña dice cual: puede haber dos en la pantalla. */
export function nombreDelBotonDeContrasena(etiqueta: string, visible: boolean): string {
  return `${visible ? 'Ocultar' : 'Mostrar'} ${etiqueta.toLowerCase()}`;
}
```

`src/components/formularios/Campo.tsx`:

```tsx
import type { ComponentProps } from 'react';
import { Input } from '@/components/ui/input';
import { Label } from '@/components/ui/label';
import { atributosDeError, idDelError } from '@/lib/formularios/accesibilidad';

export type PropsDeCampo = ComponentProps<'input'> & {
  id: string;
  etiqueta: string;
  error?: string;
};

/** El mensaje de error debajo de un campo. */
export function ErrorDeCampo({ id, error }: { id: string; error?: string }) {
  if (!error) return null;
  return (
    <p id={idDelError(id)} className="text-destructive text-sm">
      {error}
    </p>
  );
}

/** Un campo con su etiqueta y, si hace falta, su error, que el lector de pantalla anuncia. */
export function Campo({ id, etiqueta, error, ...props }: PropsDeCampo) {
  return (
    <div className="space-y-2">
      <Label htmlFor={id}>{etiqueta}</Label>
      <Input {...props} id={id} {...atributosDeError(id, error)} />
      <ErrorDeCampo id={id} error={error} />
    </div>
  );
}
```

```tsx
'use client';

import { Eye, EyeOff } from 'lucide-react';
import { useState } from 'react';
import { Button } from '@/components/ui/button';
import { Input } from '@/components/ui/input';
import { Label } from '@/components/ui/label';
import { atributosDeError, nombreDelBotonDeContrasena } from '@/lib/formularios/accesibilidad';
import { ErrorDeCampo, type PropsDeCampo } from './Campo';

/** Contraseña con un boton para verla: en vez de pedirla dos veces, se revisa lo escrito. */
export function CampoContrasena({ id, etiqueta, error, ...props }: Omit<PropsDeCampo, 'type'>) {
  const [visible, setVisible] = useState(false);
  return (
    <div className="space-y-2">
      <Label htmlFor={id}>{etiqueta}</Label>
      <div className="flex gap-2">
        <Input
          {...props}
          id={id}
          type={visible ? 'text' : 'password'}
          {...atributosDeError(id, error)}
        />
        <Button
          type="button"
          variant="outline"
          size="icon"
          aria-label={nombreDelBotonDeContrasena(etiqueta, visible)}
          aria-controls={id}
          onClick={() => setVisible(!visible)}
        >
          {visible ? <EyeOff aria-hidden /> : <Eye aria-hidden />}
        </Button>
      </div>
      <ErrorDeCampo id={id} error={error} />
    </div>
  );
}
```

```ts
import { createServerClient } from '@supabase/ssr';
import { NextResponse, type NextRequest } from 'next/server';
import { requiereSesion } from '../acceso/estados';
import { leerEntornoPublico } from '../entorno/publico';
import type { Database } from './tipos';

type Salida = { respuesta: NextResponse };

// Las cookies renovadas van al pedido (para lo que se arme despues) y a la respuesta (para el
// navegador). Las cabeceras evitan que una cache guarde la sesion de otra persona.
function clienteDelPedido(pedido: NextRequest, salida: Salida) {
  const entorno = leerEntornoPublico();
  return createServerClient<Database>(
    entorno.NEXT_PUBLIC_SUPABASE_URL,
    entorno.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY,
    {
      cookies: {
        getAll: () => pedido.cookies.getAll(),
        setAll: (galletas, cabeceras) => {
          galletas.forEach(({ name, value }) => pedido.cookies.set(name, value));
          salida.respuesta = NextResponse.next({ request: pedido });
          galletas.forEach(({ name, value, options }) =>
            salida.respuesta.cookies.set(name, value, options),
          );
          Object.entries(cabeceras).forEach(([clave, valor]) => salida.respuesta.headers.set(clave, valor));
        },
      },
    },
  );
}

function alIngreso(pedido: NextRequest): NextResponse {
  const destino = pedido.nextUrl.clone();
  destino.pathname = '/admin/ingresar';
  destino.search = '';
  return NextResponse.redirect(destino);
}

/** Refresca la sesion vencida y manda al ingreso a quien pide el panel sin sesion. */
export async function actualizarSesion(pedido: NextRequest): Promise<NextResponse> {
  const salida: Salida = { respuesta: NextResponse.next({ request: pedido }) };
  const supabase = clienteDelPedido(pedido, salida);
  // Nada entre crear el cliente y getClaims: es lo que refresca una sesion vencida.
  const { data } = await supabase.auth.getClaims();
  if (!data?.claims && requiereSesion(pedido.nextUrl.pathname)) return alIngreso(pedido);
  return salida.respuesta;
}
```

```ts
import type { z } from 'zod';
import { exito, fallo, type Resultado } from '../resultado';
import type { Cliente } from '../supabase/cliente';
import { crearClienteDelServidor } from '../supabase/servidor';
import { contarPendientes, perfilPropio } from '../usuarios/consultas';
import { MENSAJES } from '../usuarios/errores';
import {
  destinoDe,
  estadoDeAcceso,
  type EstadoDeAcceso,
  type Pagina,
  type PerfilDeAcceso,
} from './estados';
import { enlacesDelMarco, type EnlaceDelMarco } from './marco';

export type PaginaConSesion = Exclude<Pagina, 'publica'>;
export type Acceso = { cliente: Cliente; perfil: PerfilDeAcceso; estado: EstadoDeAcceso };

// cache: el layout, la pagina y la accion de un mismo pedido leen el perfil una sola vez.
const accesoActual = cache(async () => {
  const cliente = await crearClienteDelServidor();
  const perfil = await perfilPropio(cliente);
  return { cliente, perfil, estado: estadoDeAcceso(perfil) };
});

/** Cuantos esperan un rol en el local de quien pide, leido una vez por pedido. */
export const pendientesActuales = cache((cliente: Cliente) => contarPendientes(cliente));

/** Ingreso y registro: quien ya tiene sesion va a su pantalla. */
export async function soloSinSesion(): Promise<void> {
  const destino = destinoDe((await accesoActual()).estado, 'publica');
  if (destino) redirect(destino);
}

/** Cada pagina con sesion: manda a quien no puede verla adonde le corresponde. */
export async function exigirPagina(pagina: PaginaConSesion): Promise<Acceso> {
  const { cliente, perfil, estado } = await accesoActual();
  const destino = destinoDe(estado, pagina);
  if (destino || !perfil) redirect(destino ?? '/admin/ingresar');
  return { cliente, perfil, estado };
}

/** Cada accion con sesion: el acceso, o el mensaje para la persona si no puede. */
export async function exigirAccion(pagina: PaginaConSesion): Promise<Resultado<Acceso>> {
  const { cliente, perfil, estado } = await accesoActual();
  if (!perfil) return fallo(MENSAJES.sesionVencida);
  if (estado === 'desactivado') return fallo(MENSAJES.desactivada);
  if (destinoDe(estado, pagina)) return fallo(MENSAJES.sinPermiso);
  return exito({ cliente, perfil, estado });
}

/** Lo comun de cada accion: el acceso, el mismo esquema del formulario y el panel al dia. */
export async function ejecutarAccion<T, R>(
  pagina: PaginaConSesion,
  esquema: z.ZodType<T>,
  datos: unknown,
  hacer: (acceso: Acceso, validos: T) => Promise<Resultado<R>>,
): Promise<Resultado<R>> {
  const acceso = await exigirAccion(pagina);
  if (!acceso.ok) return acceso;
  const validos = esquema.safeParse(datos);
  if (!validos.success) return fallo(MENSAJES.datosInvalidos);
  const resultado = await hacer(acceso.datos, validos.data);
  revalidatePath('/admin', 'layout');
  return resultado;
}

/** Lo que muestra el marco del panel: el nombre y los enlaces, con los pendientes del admin. */
export async function datosDelMarco({ cliente, perfil, estado }: Acceso): Promise<{
  nombre: string;
  enlaces: EnlaceDelMarco[];
}> {
  const pendientes = estado === 'admin' ? await pendientesActuales(cliente) : 0;
  return { nombre: perfil.nombre, enlaces: enlacesDelMarco(estado, pendientes) };
```

```ts
import { useState } from 'react';
import type { Resultado } from '../resultado';

type Estado = { mensaje: string | null; listo: boolean };

/** Manda los datos a una accion de servidor y guarda si salio bien o el mensaje de por que no. */
export function useEnvio<T, R>(
  accion: (datos: T) => Promise<Resultado<R>>,
  alTerminar?: (datos: R) => void,
) {
  const [estado, setEstado] = useState<Estado>({ mensaje: null, listo: false });
  async function enviar(datos: T): Promise<void> {
    setEstado({ mensaje: null, listo: false });
    const resultado = await accion(datos);
    if (!resultado.ok) {
      setEstado({ mensaje: resultado.mensaje, listo: false });
      return;
    }
    setEstado({ mensaje: null, listo: true });
    alTerminar?.(resultado.datos);
  }
  return { ...estado, enviar };
}
```

```ts
import { NextResponse, type NextRequest } from 'next/server';
import { crearClienteDelServidor } from '@/lib/supabase/servidor';
import { salir } from '@/lib/usuarios/cuentas';

// GET cuando el panel echa a una cuenta desactivada; POST desde el boton Salir.
async function cerrarSesion(pedido: NextRequest): Promise<NextResponse> {
  await salir(await crearClienteDelServidor());
  const destino = new URL('/admin/ingresar', pedido.url);
  if (pedido.nextUrl.searchParams.get('motivo') === 'desactivada') {
    destino.searchParams.set('motivo', 'desactivada');
  }
  // 303: despues de un POST, el navegador pide el ingreso con GET.
  return NextResponse.redirect(destino, 303);
}

export const GET = cerrarSesion;
export const POST = cerrarSesion;
```

```ts
  if (accion === 'corregir') return { tipo: 'corregir' };
```

```ts
import { useState, useTransition } from 'react';
import { panelAlElegir, siguientePanel, type Panel } from '@/lib/usuarios/pantalla';
import type { AccionDeUsuario } from '@/lib/usuarios/presentacion';
import { OPERACIONES, type Operable } from './operaciones';

// Corre una operacion en el servidor y deja el mensaje si no se pudo.
function useOperacion(id: string, alTerminar: (panel: Panel) => void) {
  const [mensaje, setMensaje] = useState<string | null>(null);
  const [enviando, iniciar] = useTransition();
  function ejecutar(accion: Operable) {
    setMensaje(null);
    iniciar(async () => {
      const resultado = await OPERACIONES[accion](id);
      if (!resultado.ok) setMensaje(resultado.mensaje);
      alTerminar(siguientePanel(resultado));
    });
  }
  return { mensaje, enviando, ejecutar };
}

/** Que muestra la tarjeta de una cuenta: los botones, una confirmacion, la correccion o la temporal. */
export function useAccionesDeUsuario(id: string) {
  const [panel, setPanel] = useState<Panel>({ tipo: 'botones' });
  const operacion = useOperacion(id, setPanel);
  function elegir(accion: AccionDeUsuario) {
    const siguiente = panelAlElegir(accion);
    setPanel(siguiente);
    if (siguiente.tipo === 'botones' && accion !== 'corregir') operacion.ejecutar(accion);
  }
  return { ...operacion, panel, elegir, volver: () => setPanel({ tipo: 'botones' }) };
}
```

```tsx
  if (paginas === 1) return null;
  const { pagina } = filtros;
  return (
    <nav aria-label="Páginas" className="flex items-center gap-4 text-sm">
      {pagina > 1 ? (
        <Link href={enlaceDeUsuarios({ ...filtros, pagina: pagina - 1 })} className="underline underline-offset-4">
          Anterior
        </Link>
      ) : null}
      <span>
        Página {pagina} de {paginas}
      </span>
      {pagina < paginas ? (
        <Link href={enlaceDeUsuarios({ ...filtros, pagina: pagina + 1 })} className="underline underline-offset-4">
          Siguiente
        </Link>
      ) : null}
    </nav>
  );
}
```
