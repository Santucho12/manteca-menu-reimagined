# Reportes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Los siete reportes de `docs/modulos/08-reportes.md` (ventas por período, producto y
categoría; gastos por categoría y período; caja; resultado), con filtro de fechas, comparación,
tabla, gráfico y total.

**Architecture:** Cuatro funciones de lectura en la base (solo admin) dan las ventas y los gastos
agregados; un juego de funciones puras en `src/lib/reportes/` arma períodos, comparaciones,
agrupaciones, resultado y caja; cada reporte es una página server de Next que lee, calcula y
dibuja con componentes compartidos y gráficos de Recharts.

**Tech Stack:** Next.js 16 App Router, Supabase (Postgres + RLS), TypeScript, Vitest, Playwright,
Recharts 3.10.1.

**Spec:** `docs/superpowers/specs/2026-10-11-reportes-design.md`

## Global Constraints

- TDD estricto: test, verlo fallar, código, verlo pasar. Sin mocks (`vi.mock`, `vi.fn`,
  `page.route`): lo que toca datos va contra la base de pruebas.
- `*.base.test.ts` usa la base (grupo `base`); cualquier otro `*.test.ts` es puro (grupo `puros`).
- 20 líneas por función en `.ts`, 80 por componente `.tsx`, 300 por archivo (sin blancos ni
  comentarios). La lógica vive en `.ts`, no en los `.tsx`.
- Español en nombres, comentarios y base; pantallas en rioplatense con voseo.
- Plata en centavos enteros (`number` entero, nombres con `Centavos`/`_centavos`); se muestra con
  `formatearPesos` (`$1.234,50`). Nunca la palabra "margen".
- Lo cancelado y lo anulado no cuentan. El día es el día en Argentina (`fecha` ya lo guarda).
- Solo el admin entra a Reportes; caja, encargado, invitado y desactivado reciben rechazo.
- Las versiones van exactas en `package.json`, sin `^`.
- Solo Santiago autoriza aplicar migraciones a la base real, mergear y publicar.
- Hecho es `npm run verificar` y `npm run e2e` en verde. Mientras se construye: los tests nuevos
  de la tarea y `npm run tipos` al cerrarla.
- Commits en español con conventional commits; cada archivo con su ruta, nunca `git add -A`.

## Review Focus

1. Un período que cruza el cambio de año o de mes con días de 28/29/30/31: el período anterior
   del mismo largo y la agrupación por mes tienen que caer en los días correctos.
2. Desde posterior a hasta en la URL, o fechas inválidas (`2026-02-30`): se ordenan o se ignoran,
   nunca rompen la página.
3. Comparación contra un período sin datos: "Sin datos para comparar", nunca un porcentaje
   dividido por cero ni `NaN`.
4. Ventas de productos sin vincular (renglones con `producto_id` nulo): una fila "Sin vincular"
   en producto y categoría, que suma al total.
5. Un rol que no es admin llamando a las funciones de la base directamente: rechazo `42501`, no
   filas vacías ni filas de su cierre.

Cada línea tiene su test: 1 y 2 en la Tarea 2, 3 en la Tarea 3, 4 en las Tareas 1 y 4, 5 en la
Tarea 1.

```ts
import { clienteSecretoDePruebas } from './clientes';
import { idDelLocalPrincipal } from './locales';
import type { ParaVender } from './ventas-de-prueba';

type RenglonSembrado = {
  producto: ParaVender | null;
  cantidad: number;
  precioCentavos: number;
  /** El nombre de un producto de Fudo sin vincular. */
  descripcion?: string;
};
export type SemillaConRenglones = {
  fecha: string;
  estado?: 'cerrada' | 'cancelada';
  anulado?: boolean;
  renglones: RenglonSembrado[];
};

const subtotalDe = (r: RenglonSembrado) => Math.round(r.cantidad * r.precioCentavos);

async function insertarVenta(semilla: SemillaConRenglones, local: string): Promise<string> {
  const { data, error } = await clienteSecretoDePruebas()
    .from('ventas')
    .insert({
      local_id: local,
      fecha: semilla.fecha,
      estado: semilla.estado ?? 'cerrada',
      anulado: semilla.anulado ?? false,
      motivo_anulacion: semilla.anulado ? 'Prueba de reportes' : null,
      total_centavos: semilla.renglones.reduce((suma, r) => suma + subtotalDe(r), 0),
    })
    .select('id')
    .single();
  if (error) throw new Error(`No pude sembrar la venta: ${error.message}`);
  return data.id;
}

/** Una venta con sus renglones escrita directo, para leerla desde los reportes. */
export async function sembrarVentaConRenglones(semilla: SemillaConRenglones): Promise<string> {
  const local = await idDelLocalPrincipal(clienteSecretoDePruebas());
  const id = await insertarVenta(semilla, local);
  const renglones = semilla.renglones.map((r) => ({
    local_id: local,
    venta_id: id,
    producto_id: r.producto?.productoId ?? null,
    presentacion_id: r.producto?.presentacionId ?? null,
    descripcion: r.descripcion ?? r.producto?.texto ?? 'Sin nombre',
    cantidad: r.cantidad,
    precio_unitario_centavos: r.precioCentavos,
    subtotal_centavos: subtotalDe(r),
  }));
  const { error } = await clienteSecretoDePruebas().from('renglones_de_venta').insert(renglones);
  if (error) throw new Error(`No pude sembrar los renglones: ${error.message}`);
  return id;
}
```

```sql
-- Reportes: lecturas agregadas de ventas y gastos que comparten Reportes e Inicio. Solo un
-- admin activo: Caja lee sus cierres y los gastos de su cierre y no tiene que ver esto. Lo
-- cancelado y lo anulado no cuentan; el dia es la fecha en Argentina que ya guarda cada fila.

create or replace function public.reportes_exigir_admin()
returns void
language plpgsql
stable
security invoker
set search_path = ''
as $$
begin
  if not public.es_admin_activo() then
    raise exception 'No tenes permiso para ver los reportes' using errcode = '42501';
  end if;
end
$$;

create or replace function public.reporte_ventas_por_dia(desde date, hasta date)
returns table (dia date, ventas bigint, monto_centavos bigint)
language plpgsql
stable
security invoker
set search_path = ''
as $$
#variable_conflict use_column
begin
  perform public.reportes_exigir_admin();
  return query
    select v.fecha, count(*), coalesce(sum(v.total_centavos), 0)::bigint
      from public.ventas v
     where v.local_id = public.local_del_usuario() and v.estado = 'cerrada' and not v.anulado
       and v.fecha between desde and hasta
     group by v.fecha
     order by v.fecha;
end
$$;

-- La categoria es la de hoy del producto. Un renglon sin producto (de Fudo, sin vincular)
-- queda con su descripcion y sin categoria.
create or replace function public.reporte_ventas_por_producto(desde date, hasta date)
returns table (
  producto_id uuid, producto text, categoria_id uuid, categoria text, presentacion text,
  cantidad numeric, monto_centavos bigint
)
language plpgsql
stable
security invoker
set search_path = ''
as $$
#variable_conflict use_column
begin
  perform public.reportes_exigir_admin();
  return query
    select r.producto_id, coalesce(p.nombre, r.descripcion), c.id, c.nombre,
           coalesce(pr.nombre, ''), sum(r.cantidad), sum(r.subtotal_centavos)::bigint
      from public.renglones_de_venta r
      join public.ventas v on v.id = r.venta_id
      left join public.productos p on p.id = r.producto_id
      left join public.categorias c on c.id = p.categoria_id
      left join public.presentaciones pr on pr.id = r.presentacion_id
     where v.local_id = public.local_del_usuario() and v.estado = 'cerrada' and not v.anulado
       and v.fecha between desde and hasta
     group by r.producto_id, coalesce(p.nombre, r.descripcion), c.id, c.nombre, coalesce(pr.nombre, '')
     order by 7 desc, 2;
end
$$;

create or replace function public.reporte_ventas_por_categoria(desde date, hasta date)
returns table (categoria_id uuid, categoria text, ventas bigint, monto_centavos bigint)
language plpgsql
stable
security invoker
set search_path = ''
as $$
#variable_conflict use_column
begin
  perform public.reportes_exigir_admin();
  return query
    select c.id, coalesce(c.nombre, 'Sin vincular'), count(distinct v.id),
           sum(r.subtotal_centavos)::bigint
      from public.renglones_de_venta r
      join public.ventas v on v.id = r.venta_id
      left join public.productos p on p.id = r.producto_id
      left join public.categorias c on c.id = p.categoria_id
     where v.local_id = public.local_del_usuario() and v.estado = 'cerrada' and not v.anulado
       and v.fecha between desde and hasta
     group by c.id, c.nombre
     order by 4 desc, 2;
end
$$;

create or replace function public.reporte_gastos(desde date, hasta date)
returns table (dia date, categoria_id uuid, categoria text, monto_centavos bigint)
language plpgsql
stable
security invoker
set search_path = ''
as $$
#variable_conflict use_column
begin
  perform public.reportes_exigir_admin();
  return query
    select g.fecha, g.categoria_id, cg.nombre, sum(g.monto_centavos)::bigint
      from public.gastos g
      join public.categorias_de_gasto cg on cg.id = g.categoria_id
     where g.local_id = public.local_del_usuario() and not g.anulado
       and g.fecha between desde and hasta
     group by g.fecha, g.categoria_id, cg.nombre
     order by g.fecha, cg.nombre;
end
$$;

revoke all on function public.reportes_exigir_admin() from public, anon;
revoke all on function public.reporte_ventas_por_dia(date, date) from public, anon;
revoke all on function public.reporte_ventas_por_producto(date, date) from public, anon;
revoke all on function public.reporte_ventas_por_categoria(date, date) from public, anon;
revoke all on function public.reporte_gastos(date, date) from public, anon;
grant execute on function public.reportes_exigir_admin() to authenticated;
```

```ts
import { esFechaValida } from '../gastos/vencimientos';
import { numeroDePagina, unValor } from '../usuarios/presentacion';

export type Periodo = { desde: string; hasta: string };
export type PeriodosDelReporte = {
  actual: Periodo;
  comparacion: Periodo;
  comparacionElegida: boolean;
  pagina: number;
};
export type ParametrosDeReporte = Record<string, string | string[] | undefined>;

const UN_DIA = 86_400_000;
const aTiempo = (dia: string) => Date.parse(`${dia}T00:00:00Z`);
const aDia = (tiempo: number) => new Date(tiempo).toISOString().slice(0, 10);

export const sumarDias = (dia: string, dias: number) => aDia(aTiempo(dia) + dias * UN_DIA);
export const diasDe = (periodo: Periodo) =>
  Math.round((aTiempo(periodo.hasta) - aTiempo(periodo.desde)) / UN_DIA) + 1;

/** El periodo del mismo largo que termina el dia antes de que empiece este. */
export function periodoAnterior(periodo: Periodo): Periodo {
  return { desde: sumarDias(periodo.desde, -diasDe(periodo)), hasta: sumarDias(periodo.desde, -1) };
}

const fechaDe = (texto: string | undefined) => (texto && esFechaValida(texto) ? texto : null);
const ordenado = (a: string, b: string): Periodo => (a <= b ? { desde: a, hasta: b } : { desde: b, hasta: a });

function elegida(parametros: ParametrosDeReporte): Periodo | null {
  const desde = fechaDe(unValor(parametros.cdesde));
  const hasta = fechaDe(unValor(parametros.chasta));
  return desde && hasta ? ordenado(desde, hasta) : null;
}

/** El periodo y la comparacion, leidos de la URL; sin fechas, el mes de hoy en Argentina. */
export function periodosDelReporte(parametros: ParametrosDeReporte, hoy: string): PeriodosDelReporte {
  const mes = mesDe(hoy);
  const actual = ordenado(
    fechaDe(unValor(parametros.desde)) ?? mes.desde,
    fechaDe(unValor(parametros.hasta)) ?? mes.hasta,
  );
  const comparacion = elegida(parametros);
  return {
    actual,
    comparacion: comparacion ?? periodoAnterior(actual),
    comparacionElegida: comparacion !== null,
    pagina: numeroDePagina(unValor(parametros.pagina)),
  };
}

export function atajos(hoy: string): { texto: string; periodo: Periodo }[] {
  const mes = mesDe(hoy);
  return [
    { texto: 'Este mes', periodo: mes },
    { texto: 'Mes pasado', periodo: mesDe(sumarDias(mes.desde, -1)) },
    { texto: 'Últimos 7 días', periodo: { desde: sumarDias(hoy, -6), hasta: hoy } },
  ];
}

export function enlaceDeReporte(
  ruta: string,
  periodos: { actual: Periodo; comparacion?: Periodo | null; pagina?: number },
): string {
  const parametros = new URLSearchParams(periodos.actual);
  if (periodos.comparacion) {
    parametros.set('cdesde', periodos.comparacion.desde);
    parametros.set('chasta', periodos.comparacion.hasta);
  }
  if (periodos.pagina && periodos.pagina > 1) parametros.set('pagina', String(periodos.pagina));
  return `${ruta}?${parametros.toString()}`;
}

  `del ${fechaParaMostrar(periodo.desde)} al ${fechaParaMostrar(periodo.hasta)}`;
```

```ts
import { formatearPesos } from '../plata';

export type Variacion = { diferenciaCentavos: number; porcentaje: number | null } | null;

/** Contra un periodo sin datos no hay variacion; contra cero, solo la diferencia. */
export function variacion(actual: number, anterior: number | null): Variacion {
  if (anterior === null) return null;
  const diferenciaCentavos = actual - anterior;
  const porcentaje =
    anterior === 0 ? null : Math.round((diferenciaCentavos * 1000) / anterior) / 10;
  return { diferenciaCentavos, porcentaje };
}

/** Cada fila contra la misma del otro periodo; sin el otro periodo, ninguna compara. */
export function compararFilas<T>(
  actuales: T[],
  anteriores: T[] | null,
  clave: (fila: T) => string,
  monto: (fila: T) => number,
): { fila: T; variacion: Variacion }[] {
  const previos = new Map((anteriores ?? []).map((f) => [clave(f), monto(f)]));
  return actuales.map((fila) => ({
    fila,
    variacion: variacion(monto(fila), previos.get(clave(fila)) ?? null),
  }));
}

const signo = (numero: number) => (numero > 0 ? '+' : numero < 0 ? '-' : '');
const porciento = (p: number) => `${signo(p)}${String(Math.abs(p)).replace('.', ',')} %`;

export function textoDeVariacion(v: Variacion): string {
  if (!v) return 'Sin datos para comparar';
  const pesos = `${signo(v.diferenciaCentavos)}${formatearPesos(Math.abs(v.diferenciaCentavos))}`;
  return v.porcentaje === null ? pesos : `${pesos} (${porciento(v.porcentaje)})`;
}
```

```ts
import { diasDe, sumarDias, type Periodo } from './periodos';

export type Escala = 'dia' | 'mes';
export type Punto = { clave: string; montoCentavos: number; cantidad: number };
export type PuntoSuperpuesto = {
  posicion: number;
  etiqueta: string;
  actual: number;
  comparacion: number | null;
};

const MESES = ['ene', 'feb', 'mar', 'abr', 'may', 'jun', 'jul', 'ago', 'sep', 'oct', 'nov', 'dic'];

export const escalaDe = (periodo: Periodo): Escala => (diasDe(periodo) <= 62 ? 'dia' : 'mes');

/** Por dia quedan como estan; por mes se suman los dias de cada mes. */
export function agrupar(puntos: Punto[], escala: Escala): Punto[] {
  if (escala === 'dia') return puntos;
  const meses = new Map<string, Punto>();
  for (const p of puntos) {
    const clave = p.clave.slice(0, 7);
    const previo = meses.get(clave) ?? { clave, montoCentavos: 0, cantidad: 0 };
    meses.set(clave, {
      clave,
      montoCentavos: previo.montoCentavos + p.montoCentavos,
      cantidad: previo.cantidad + p.cantidad,
    });
  }
  return [...meses.values()];
}

function mesSiguiente(mes: string): string {
  const [anio, numero] = mes.split('-').map(Number) as [number, number];
  return numero === 12 ? `${anio + 1}-01` : `${anio}-${String(numero + 1).padStart(2, '0')}`;
}

/** Cada dia o cada mes del periodo, en orden. */
export function clavesDe(periodo: Periodo, escala: Escala): string[] {
  const claves: string[] = [];
  if (escala === 'dia') {
    for (let d = periodo.desde; d <= periodo.hasta; d = sumarDias(d, 1)) claves.push(d);
    return claves;
  }
  for (let m = periodo.desde.slice(0, 7); m <= periodo.hasta.slice(0, 7); m = mesSiguiente(m)) {
    claves.push(m);
  }
  return claves;
}

export function etiquetaDe(clave: string, escala: Escala): string {
  if (escala === 'dia') return `${clave.slice(8, 10)}/${clave.slice(5, 7)}`;
  return `${MESES[Number(clave.slice(5, 7)) - 1]} ${clave.slice(0, 4)}`;
}

type Lado = { periodo: Periodo; puntos: Punto[] };

function montosDe(lado: Lado, escala: Escala): number[] {
  const montos = new Map(agrupar(lado.puntos, escala).map((p) => [p.clave, p.montoCentavos]));
  return clavesDe(lado.periodo, escala).map((clave) => montos.get(clave) ?? 0);
}

/** Los dos periodos uno sobre otro: el dia 1 de cada uno en la misma posicion. */
export function serieSuperpuesta(actual: Lado, comparado: Lado, escala: Escala): PuntoSuperpuesto[] {
  const otros = montosDe(comparado, escala);
  const claves = clavesDe(actual.periodo, escala);
  return montosDe(actual, escala).map((monto, i) => ({
    posicion: i + 1,
    etiqueta: etiquetaDe(claves[i]!, escala),
    actual: monto,
    comparacion: otros[i] ?? null,
  }));
}
```

```ts
export type CategoriaDelReporte = { clave: string; nombre: string; ventas: number; montoCentavos: number };

export const ticketPromedio = (montoCentavos: number, ventas: number) =>

export function totalesDeVentas(dias: VentaDelDia[]): TotalesDeVentas {
  const montoCentavos = dias.reduce((suma, d) => suma + d.monto_centavos, 0);
  const ventas = dias.reduce((suma, d) => suma + d.ventas, 0);

  dias.map((d) => ({ clave: d.dia, montoCentavos: d.monto_centavos, cantidad: d.ventas }));

const porMonto = <T extends { montoCentavos: number }>(a: T, b: T) => b.montoCentavos - a.montoCentavos;

function detalleDe(r: RenglonDeProducto): Detalle {
  // Lo no vinculado no tiene presentacion: el detalle es el nombre que trajo Fudo.
  const nombre = r.producto_id ? r.presentacion : r.producto;
  return { nombre, cantidad: r.cantidad, montoCentavos: r.monto_centavos };
}

/** Una fila por producto con su monto; lo no vinculado, junto en "Sin vincular". */
export function productosDelReporte(renglones: RenglonDeProducto[]): ProductoDelReporte[] {
  const productos = new Map<string, ProductoDelReporte>();
  for (const r of renglones) {
    const clave = r.producto_id ?? SIN_VINCULAR;
    const nombre = r.producto_id ? r.producto : 'Sin vincular';
    const previo = productos.get(clave) ?? { clave, nombre, montoCentavos: 0, presentaciones: [] };
    productos.set(clave, {
      ...previo,
      montoCentavos: previo.montoCentavos + r.monto_centavos,
      presentaciones: [...previo.presentaciones, detalleDe(r)],
    });
  }
  return [...productos.values()]
    .map((p) => (p.clave === SIN_VINCULAR ? p : { ...p, presentaciones: p.presentaciones.sort(porMonto) }))
    .sort((a, b) => Number(a.clave === SIN_VINCULAR) - Number(b.clave === SIN_VINCULAR) || porMonto(a, b));
```

```ts
import type { Punto } from './agrupar';

export type GastoDelDia = { dia: string; categoria_id: string; categoria: string; monto_centavos: number };
export type FilaDeGasto = { clave: string; nombre: string; montoCentavos: number };

export const totalDeGastos = (filas: GastoDelDia[]) =>
  filas.reduce((suma, f) => suma + f.monto_centavos, 0);

export function gastosPorCategoria(filas: GastoDelDia[]): FilaDeGasto[] {
  const categorias = new Map<string, FilaDeGasto>();
  for (const f of filas) {
    const previo = categorias.get(f.categoria_id) ?? { clave: f.categoria_id, nombre: f.categoria, montoCentavos: 0 };
    categorias.set(f.categoria_id, { ...previo, montoCentavos: previo.montoCentavos + f.monto_centavos });
  }
  return [...categorias.values()].sort((a, b) => b.montoCentavos - a.montoCentavos);
}

export function puntosDeGastos(filas: GastoDelDia[]): Punto[] {
  const dias = new Map<string, number>();
  for (const f of filas) dias.set(f.dia, (dias.get(f.dia) ?? 0) + f.monto_centavos);
  return [...dias.entries()]
    .sort(([a], [b]) => a.localeCompare(b))
    .map(([clave, montoCentavos]) => ({ clave, montoCentavos, cantidad: 0 }));
}
```

```ts
export type ResultadoDelPeriodo = {
  ventasCentavos: number;
  gastosCentavos: number;
  /** Nulo sin gastos cargados: un mes de antes del sistema tiene ventas pero no gastos. */
  resultadoCentavos: number | null;
  categorias: FilaDeGasto[];

export type ResultadoDelMes = {
  mes: string;
  ventasCentavos: number;
  gastosCentavos: number;
  resultadoCentavos: number | null;
};

const totalDeVentas = (dias: VentaDelDia[]) => dias.reduce((s, d) => s + d.monto_centavos, 0);

export function resultadoDelPeriodo(dias: VentaDelDia[], gastos: GastoDelDia[]): ResultadoDelPeriodo {
  const ventasCentavos = totalDeVentas(dias);
  const gastosCentavos = totalDeGastos(gastos);
  return {
    ventasCentavos,
    gastosCentavos,
    resultadoCentavos: gastos.length === 0 ? null : ventasCentavos - gastosCentavos,
    categorias: gastosPorCategoria(gastos),
  };
}

export function resultadoPorMes(dias: VentaDelDia[], gastos: GastoDelDia[]): ResultadoDelMes[] {
  const meses = [...new Set([...dias.map((d) => d.dia), ...gastos.map((g) => g.dia)].map((d) => d.slice(0, 7)))].sort();
  return meses.map((mes) => {
    const r = resultadoDelPeriodo(
      dias.filter((d) => d.dia.startsWith(mes)),
      gastos.filter((g) => g.dia.startsWith(mes)),
    );
    return { mes, ventasCentavos: r.ventasCentavos, gastosCentavos: r.gastosCentavos, resultadoCentavos: r.resultadoCentavos };
  });
}
```

```ts
  periodo: Periodo,
  primero: string | null,
  hoy: string,
): FilaDeCaja[] {
  const faltan = diasSinCierre({
    ...periodo,
    conCierre: cierres.map((c) => c.fecha),
    primero,
    hoy: sumarDias(hoy, -1),
  });
  return [
    ...cierres.map((cierre) => ({ fecha: cierre.fecha, cierre })),
    ...faltan.map((fecha) => ({ fecha, cierre: null })),
  ].sort((a, b) => b.fecha.localeCompare(a.fecha));
}

function sumarDiferencia(previa: number | null, nueva: number | null): number | null {
  if (nueva === null) return previa;
  return (previa ?? 0) + nueva;
}

export function resumenPorEmpleado(cierres: CierreDelReporte[]): ResumenDeEmpleado[] {
  const personas = new Map<string, ResumenDeEmpleado>();
  for (const c of cierres) {
    const previo = personas.get(c.persona) ?? { persona: c.persona, cierres: 0, diferenciaCentavos: null };
    personas.set(c.persona, {
      persona: c.persona,
      cierres: previo.cierres + 1,
      diferenciaCentavos: sumarDiferencia(previo.diferenciaCentavos, c.diferenciaCentavos),
    });
  }
  return [...personas.values()].sort((a, b) => a.persona.localeCompare(b.persona));
}
```

```ts
export const POR_PAGINA_DE_REPORTE = 50;

/** Una pagina de una lista ya calculada; una pagina que no existe se recorta a la ultima. */
export function paginaDe<T>(filas: T[], pagina: number) {
  const paginas = Math.max(1, Math.ceil(filas.length / POR_PAGINA_DE_REPORTE));
  const actual = Math.min(Math.max(1, pagina), paginas);
  const desde = (actual - 1) * POR_PAGINA_DE_REPORTE;
  return { filas: filas.slice(desde, desde + POR_PAGINA_DE_REPORTE), pagina: actual, paginas };
}
```

```ts
  const declaradoCentavos =
    c.efectivo_centavos + c.credito_centavos + c.debito_centavos + c.qr_centavos + c.transferencia_centavos;
  return { fecha: c.fecha, persona: c.persona?.nombre ?? '', declaradoCentavos, diferenciaCentavos: diferenciaTotalDe(c) };
}

/** Los cierres sin anular del periodo. RLS deja leer todos solo al admin. */
export async function cierresDelPeriodo(cliente: Cliente, p: Periodo): Promise<CierreDelReporte[]> {
  const respuesta = await cliente
    .from('cierres_de_caja')
    .select(COLUMNAS_DE_CIERRE)
    .eq('anulado', false)
    .gte('fecha', p.desde)
    .lte('fecha', p.hasta)
    .order('fecha', { ascending: false });
  return leido<CierreLeido>(respuesta).map(aCierre);
}
```

```tsx
export const metadata: Metadata = { title: 'Ventas por período' };

const ticket = (p: Punto) => ticketPromedio(p.montoCentavos, p.cantidad);

function TablaDeVentas({ filas, escala }: { filas: Punto[]; escala: Escala }) {
  return (
    <Table>
      <TableHeader>
        <TableRow>
          <TableHead>{escala === 'dia' ? 'Día' : 'Mes'}</TableHead>
          <TableHead className="text-right">Ventas</TableHead>
          <TableHead className="text-right">Monto</TableHead>
          <TableHead className="text-right">Ticket</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        {filas.map((p) => (
          <TableRow key={p.clave}>
            <TableCell>{textoDe(p.clave, escala)}</TableCell>
            <TableCell className="text-right">{p.cantidad}</TableCell>
            <TableCell className="text-right">{formatearPesos(p.montoCentavos)}</TableCell>
            <TableCell className="text-right">{formatearPesos(ticket(p) ?? 0)}</TableCell>
          </TableRow>
        ))}
      </TableBody>
    </Table>
  );
}

function TotalesDeVentas({ actual, anterior }: { actual: VentaDelDia[]; anterior: VentaDelDia[] }) {
  const a = totalesDeVentas(actual);
  const b = anterior.length ? totalesDeVentas(anterior) : null;
  return (
    <Totales
      items={[
        { etiqueta: 'Ventas', valor: formatearPesos(a.montoCentavos), variacion: variacion(a.montoCentavos, b?.montoCentavos ?? null) },
        { etiqueta: 'Cantidad de ventas', valor: String(a.ventas) },
        { etiqueta: 'Ticket promedio', valor: formatearPesos(a.ticketCentavos ?? 0), variacion: variacion(a.ticketCentavos ?? 0, b?.ticketCentavos ?? null) },
      ]}
    />
  );
}

export default async function ReporteDeVentas({ searchParams }: { searchParams: Promise<ParametrosDeReporte> }) {
  const { cliente } = await exigirPagina('admin');
  const hoy = diaEnArgentina(new Date());
  const periodos = periodosDelReporte(await searchParams, hoy);
  const [actual, anterior] = await Promise.all([ventasPorDia(cliente, periodos.actual), ventasPorDia(cliente, periodos.comparacion)]);
  const escala = escalaDe(periodos.actual);
  const pagina = paginaDe(agrupar(puntosDeVentas(actual), escala), periodos.pagina);
  const serie = serieSuperpuesta({ periodo: periodos.actual, puntos: puntosDeVentas(actual) }, { periodo: periodos.comparacion, puntos: puntosDeVentas(anterior) }, escala);
  return (
    <div className="space-y-6">
      <EncabezadoDeReporte titulo="Ventas por período" ruta={RUTA} periodos={periodos} hoy={hoy} />
      {actual.length === 0 ? <SinDatos>No hay ventas en este período.</SinDatos> : (
        <>
          <TotalesDeVentas actual={actual} anterior={anterior} />
          <GraficoDeLineas datos={serie} />
          <TablaDeVentas filas={pagina.filas} escala={escala} />
          <Paginas ruta={RUTA} periodos={periodos} pagina={pagina.pagina} paginas={pagina.paginas} />
        </>
      )}
    </div>
  );
}
```
